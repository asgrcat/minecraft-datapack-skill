# Java Edition 1.21.10

1.21.9のhotfixで、データパックschema変更はありません。

## JSONパラメータ差分

- **item**: 1.21.9のobject textにおけるatlas/sprite指定とprofile semanticsを継承。固有の追加・変更・削除なし
- **dimension/worldgen**: 1.21.9のnoise settings/density function schemaを継承。固有変更なし
- **enchantment**: 1.21.9の`explode.block_particles`を含むeffect schemaを継承。固有変更なし
- **variant**: 1.21.9のpainting/mob/sound variant schemaを継承。固有変更なし
- **predicate**: 直接親1.21.9のinteraction context targetを含むpredicate schemaを継承。固有の追加・変更・削除なし
- **advancement**: 直接親1.21.9のroot、criteria、trigger、reward schemaを継承。固有の追加・変更・削除なし
- **loot_table**: 直接親1.21.9のinteraction context/tableとloot function schemaを継承。固有の追加・変更・削除なし
- **recipe**: 直接親1.21.9のingredient、result、serializer schemaを継承。固有の追加・変更・削除なし
- **item_modifier**: 直接親1.21.9のloot functionとcontext source/target schemaを継承。固有の追加・変更・削除なし
- **互換性**: `min_format`/`max_format: [88,0]`を1.21.9と共有できる

## AI 生成規則

`min_format/max_format: [88,0]` と1.21.9のcommand/JSON仕様を継承します。
