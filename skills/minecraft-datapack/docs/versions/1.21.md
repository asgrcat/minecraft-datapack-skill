# Java Edition 1.21

data pack format 48。legacy data folderを原則単数形へrenameし、enchantment等をデータ駆動化します。

## folder rename

```text
advancements     → advancement
functions        → function
item_modifiers   → item_modifier
loot_tables      → loot_table
predicates       → predicate
recipes          → recipe
structures       → structure
tags/functions   → tags/function
tags/items       → tags/item
tags/blocks      → tags/block
```

他のregistry tag folderも単数形です。

## JSON

- `painting_variant`, `jukebox_song`, `enchantment`, `enchantment_provider` registry
- data-driven enchantmentのproperties/effects/conditions、availability/exclusivity tag
- `fixed_placement` placement modifier
- jukebox song/painting resource

## コマンド/NBT

- `@n` nearest entity selector
- attribute modifierの UUID+nameをnamespaced `id` 1つへ
- item argumentで `!component` によるdefault component削除
- entity/item attribute NBTを `id/base/modifiers/operation` の新形式へ

## 互換性

旧複数形folderは移動必須です。1.20.6との複数バージョン対応はoverlayでfolder treeを分けます。

## JSONパラメータ差分

- **item**: `attribute_modifiers`のUUID+nameをnamespaced `id`へ統合し、commandのitem argumentで`!<component>`によるdefault削除を追加。`jukebox_playable`は`jukebox_song` IDを参照する
- **dimension/worldgen**: dimension/dimension typeのroot schemaは1.20.6を継承。placement modifier `minecraft:fixed_placement`とconfigured feature `minecraft:end_platform`を追加
- **enchantment**: `enchantment/`と`enchantment_provider/`を追加。definitionはproperties、effect component map、inline conditionを持ち、availability/exclusivityは`tags/enchantment/`、選択処理はproviderへ分離
- **variant**: `painting_variant/`を追加し、`width`、`height`、`asset_id`で定義。`wolf_variant`は1.20.5形式を継承し、`jukebox_song`はvariantとは別registry
- **predicate**: folderを`predicates/`から`predicate/`へ単数形rename。`random_chance_with_looting`を`random_chance_with_enchanted_bonus`へ置換し、item enchantment sub-predicateの`enchantment`を`enchantments`へ変更
- **advancement**: folderを`advancements/`から`advancement/`へ単数形rename。root、criteria、requirements、rewardとtrigger集合は1.20.6を継承
- **loot_table**: folderを`loot_tables/`から`loot_table/`へ単数形rename。`looting_enchant`を`enchanted_count_increase`へ置換し、参照する`enchantment`を明示する
- **recipe**: folderを`recipes/`から`recipe/`へ単数形rename。ingredient/result/categoryを含むrecipe codecは1.20.6を継承
- **item_modifier**: folderを`item_modifiers/`から`item_modifier/`へ単数形rename。`enchanted_count_increase`、`enchant_randomly.options`、treasure fieldを削除した`enchant_with_levels`へ移行
- **互換性**: data folderとregistry tag folderの単数形renameが必須。1.20.6の複数形treeとは同じpathで共有しない

## AI 生成規則

- 1.21以上では必ず単数形folder
- enchantment/painting/jukeboxのinline推測よりregistry entryを使う
- 1.21.2のingredient/attribute prefix変更を先取りしない
