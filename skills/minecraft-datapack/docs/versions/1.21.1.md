# Java Edition 1.21.1

crash exploit等を修正した hotfix です。1.21のデータパック/command/JSON仕様を継承します。

## JSONパラメータ差分

- **item**: 1.21のitem component、attribute modifier、`jukebox_playable` schemaを継承。固有の追加・変更・削除なし
- **dimension/worldgen**: 1.21のdimension/worldgen codecを継承。固有変更なし
- **enchantment**: 1.21のdefinition、effect、tag、provider schemaを継承。固有変更なし
- **variant**: 1.21のpainting/wolf variant schemaを継承。固有変更なし
- **predicate**: 直接親1.21の単数形folderとcondition/item/entity predicate schemaを継承。固有の追加・変更・削除なし
- **advancement**: 直接親1.21のroot、criteria、trigger、reward schemaを継承。固有の追加・変更・削除なし
- **loot_table**: 直接親1.21の単数形folder、pool、entry、condition、function schemaを継承。固有の追加・変更・削除なし
- **recipe**: 直接親1.21のingredient、result、category schemaを継承。固有の追加・変更・削除なし
- **item_modifier**: 直接親1.21の単数形folderとloot function schemaを継承。固有の追加・変更・削除なし
- **互換性**: data pack format 48と単数形folderを1.21と共有できる

## AI 生成規則

format 48、単数形folder、1.21 item/enchantment仕様を使います。
