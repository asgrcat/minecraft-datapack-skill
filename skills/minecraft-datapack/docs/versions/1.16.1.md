# Java Edition 1.16.1

Realms の安定性 hotfix です。1.16 のデータパック、command、JSON 仕様を継承します。network protocol 互換と data pack 互換は別です。

## JSONパラメータ差分

- item: `inherits: 1.16`。item、recipe、loot、predicate parameterにこのバージョン固有の変更はない
- dimension/worldgen: 1.16の初期experimental schemaを継承し、1.16.2のregistry拡張はまだ使わない
- enchantment: 1.16の固定registryとitem NBT形式を継承
- variant: 1.16を継承し、data-driven variant registryはない
- predicate: 1.16のpredicate schemaを継承し、このバージョン固有の追加・変更・削除はない
- advancement: 1.16のadvancement schemaを継承し、このバージョン固有の追加・変更・削除はない
- loot_table: 1.16のloot table schemaを継承し、このバージョン固有の追加・変更・削除はない
- recipe: 1.16のsmithingを含むrecipe schemaを継承し、このバージョン固有の追加・変更・削除はない
- item_modifier: 1.16を継承し、独立resourceは未対応。このバージョン固有の追加・変更・削除はない

## AI 生成規則

1.16と同じ experimental dimension schema を使い、1.16.2の worldgen folder を使いません。
