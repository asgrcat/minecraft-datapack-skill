# Java Edition 1.17

data pack format 7。item 操作と loot/predicate の型が変わります。

## コマンド

- `/item replace <target> with <stack> [count]`
- `/item replace <target> from <source> [modifier]`
- `/item modify <target> <modifier>`
- target/source は `entity <selector> <slot>` または `block <pos> <slot>`
- `/replaceitem` を削除
- `/debug function <function>`、`/perf`

## JSON

- `data/<namespace>/item_modifiers/<id>.json`。loot function object または配列
- loot condition `value_check`、number provider `score`
- score condition の `entity` → `target`
- item predicate `item` → `items` 配列
- `set_damage`, `set_count` に `add`。`copy_nbt.source` に storage
- advancement trigger `started_riding`, `lightning_strike`, `using_item`

## 互換性

1.16.5の `/replaceitem` は load error になるため全置換します。loot table の `set_damage` 等は型検査をやり直します。

## JSONパラメータ差分

- item: `item_modifiers/<id>.json`を追加し、loot function objectまたは配列を再利用可能にした。item predicateは`item`から`items`配列へ変更し、`/item`が`/replaceitem`を置換するが、stack固有dataはまだ旧`tag` NBT
- dimension/worldgen: 1.16.5のexperimental worldgen familyを継承し、このバージョン固有のroot parameter追加・削除はない
- enchantment: 固定registryを継承し、新しいenchantment definitionはJSONで追加できない
- variant: data-driven variant registryは未対応
- predicate: item predicateの`item`を`items`へ、block predicateの`block`を`blocks`へ変更。entity predicateにpassenger、stepping_on、lightning bolt、playerの`looking_at`等を追加
- advancement: `started_riding`、`lightning_strike`、`using_item` triggerを追加し、関連するentity/item predicateを拡張
- loot_table: `value_check` condition、score number provider、`set_damage`/`set_count`の`add`、`copy_nbt.source=storage`、`set_banner_pattern`等を追加
- recipe: 1.16.5のcrafting、cooking、smithing recipe schemaを継承し、このバージョン固有の主要parameter変更はない
- item_modifier: `item_modifiers/<id>.json`を追加。単一loot function objectまたはfunction配列を`/item modify`等から再利用可能
