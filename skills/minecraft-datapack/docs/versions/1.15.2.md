# Java Edition 1.15.2

1.15.1 を継承します。

## 差分

- gamerule `doPatrolSpawning`, `doTraderSpawning`
- F3+T が loot table/advancement まで誤って reload していた問題を修正。data pack の再読込は `/reload` を使う
- authoring schema の追加はありません

## JSONパラメータ差分

- item: `inherits: 1.15.1`。item、recipe、loot、predicate parameterにこのバージョン固有の変更はない
- dimension/worldgen: 1.15.1を継承し、custom registryは未対応
- enchantment: 1.15.1の固定registryとitem NBT形式を継承
- variant: 1.15.1を継承し、data-driven variant registryはない
- predicate: 1.15.1の独立predicate schemaを継承し、このバージョン固有の追加・変更・削除はない
- advancement: 1.15.1のadvancement schemaを継承し、このバージョン固有の追加・変更・削除はない
- loot_table: 1.15.1のloot table schemaを継承し、このバージョン固有の追加・変更・削除はない
- recipe: 1.15.1のrecipe schemaを継承し、このバージョン固有の追加・変更・削除はない
- item_modifier: 1.15.1を継承し、独立resourceは未対応。このバージョン固有の追加・変更・削除はない

## AI 生成規則

2つの gamerule の最小バージョンを1.15.2とし、F3+Tを pack reload 手段として案内しません。
