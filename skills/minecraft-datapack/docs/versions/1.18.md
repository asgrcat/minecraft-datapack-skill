# Java Edition 1.18

data pack format 8。高さと terrain generation の全面変更を含みます。

## コマンドと runtime

- `/jfr`
- 最低 Java 17
- scoreboard objective/holder/team 名の長さ制限を撤廃

## JSON/NBT

- loot `set_contents`, `set_loot_table` に block entity ID の `type` が必須
- loot function `set_potion {id:<potion>}`
- advancement trigger `fall_from_height`, `ride_entity_in_lava`
- `nether_travel.entered` → `start_position`、`exited` を削除
- Spawner `SpawnPotentials` を `{weight,data}`、`SpawnData` の内容を `SpawnData.entity` へ
- world height、noise、biome/terrain generation を全面改訂

## 互換性

custom worldgen は1.17から移植せず、1.18 server JARの `--reports --server` 出力と比較します。loot table の block entity type 欠落は load error になり得ます。

## JSONパラメータ差分

- item: 旧`tag` NBTとitem modifierを継続。lootの`set_contents`/`set_loot_table`にblock entity IDの`type`を必須化し、parameter `id`を持つ`set_potion` loot functionを追加
- dimension/worldgen: world height、dimension typeの生成範囲、noise、biome/terrain generationを全面改訂。1.17以前の定義は非互換で、1.18のvanilla dataを基底にした再作成が必要
- enchantment: 固定registryを継承し、新しいenchantment definitionはJSONで追加できない
- variant: data-driven variant registryは未対応
- predicate: 1.17.1の独立predicateとitem/entity/location/block predicate形式を継承し、このバージョン固有の主要root変更はない
- advancement: 1.17.1のadvancement trigger/condition形式を継承し、このバージョン固有の主要schema変更はない
- loot_table: `set_contents`/`set_loot_table`にblock entity IDの`type`を必須化し、`id`を取る`set_potion` functionを追加
- recipe: 1.17.1のcrafting、cooking、smithing recipe schemaを継承し、このバージョン固有の主要parameter変更はない
- item_modifier: 1.17.1のloot function object/配列形式を継承し、追加された`set_potion`も対象contextに適合するmodifierで利用可能

## AI 生成規則

- worldgen JSON は1.18 vanilla dataを基底にする
- 1.18.2の density/structure/tag schemaを先取りしない
