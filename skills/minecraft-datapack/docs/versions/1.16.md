# Java Edition 1.16

pack format は5のままですが、custom dimension、predicate、UUID/NBT に大きな変更があります。

## コマンド

- `/attribute get|base get|base set|modifier add|remove|value get`
- `/locatebiome`
- `spreadplayers ... under <maxHeight>`、spawnpoint の全 dimension 対応

## JSON と NBT

- `data/<namespace>/dimension` と `dimension_type` による custom dimension。world setting import/export は experimental
- smithing recipe
- advancement のほぼ全 trigger に player check
- predicate/advancement condition は top-level array を AND として利用可能。旧 object も一部互換
- entity predicate に vehicle、targeted entity、fishing hook
- text color `#RRGGBB`、hover event `contents`、font resource location
- UUID の `UUIDMost/UUIDLeast` 等を int array の `UUID`、owner 系を `Owner` 等へ
- attribute ID を camelCase から snake_case resource location へ

## load と安全性

reload 失敗時に以前の data を維持。required tag 欠落等の critical error は world load を停止します。custom dimension/worldgen は将来互換を保証しない experimental です。

## JSONパラメータ差分

- item: 1.15.2の旧`tag` NBTを継続し、smithing recipeを追加。item componentとitem modifierはまだない
- dimension/worldgen: experimentalなworld settings import/exportとしてcustom `dimension`と`dimension_type`を導入。1.16.0の初期export、inline参照、codecを1.16.2以降と同一視しない
- enchantment: 固定registryを継承し、新しいenchantment definitionはJSONで追加できない
- variant: data-driven variant registryは未対応。entity固有NBTによる既存variant選択を継続
- predicate: 独立predicateのtop-levelをcondition配列にでき、全要素をAND評価。entity predicateにvehicle、targeted entity、fishing hook等を追加
- advancement: 多くのtriggerのentity checkをloot condition配列で記述可能にし、ほぼ全triggerへ`player` checkを追加。旧object表現はdeprecated互換
- loot_table: 1.15.2のloot table、condition、function schemaを継承し、condition配列によるAND表現をpredicate resourceと共有
- recipe: `minecraft:smithing` recipe typeを追加し、`base`、`addition`、`result`で定義
- item_modifier: 独立item modifier resourceは未対応。1.16のloot functionを`item_modifiers/`へ置く形式は利用不可

## AI 生成規則

- 1.16.0/1.16.1の worldgen JSON を1.16.2 schema と同一視しない
- deprecated predicate object の偶然の互換より、1.16の array/condition 形を明示する
- hover event の `value` と `contents` のバージョン差を保持する
