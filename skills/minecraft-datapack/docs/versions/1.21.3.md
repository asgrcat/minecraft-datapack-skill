# Java Edition 1.21.3

1.21.2のSalmon/Realms resource pack問題等を直す hotfix です。データパックschema変更はありません。

## JSONパラメータ差分

- **item**: 1.21.2のcomponentとrecipe ingredient schemaを継承。固有の追加・変更・削除なし
- **dimension/worldgen**: 1.21.2のdimension/worldgen codecを継承。固有変更なし
- **enchantment**: 1.21.2の`change_item_damage`を含むeffect schemaを継承。固有変更なし
- **variant**: 1.21.2のpainting `author`/`title`とwolf variant schemaを継承。固有変更なし
- **predicate**: 直接親1.21.2のitem/component/entity predicate schemaを継承。固有の追加・変更・削除なし
- **advancement**: 直接親1.21.2の`killed_by_arrow`を含むtrigger schemaを継承。固有の追加・変更・削除なし
- **loot_table**: 直接親1.21.2のroot、pool、entry、condition、function schemaを継承。固有の追加・変更・削除なし
- **recipe**: 直接親1.21.2のinline ingredientと`crafting_transmute` schemaを継承。固有の追加・変更・削除なし
- **item_modifier**: 直接親1.21.2のloot functionとcomponent codecを継承。固有の追加・変更・削除なし
- **互換性**: data pack format 57を1.21.2と共有できる

## AI 生成規則

1.21.2のingredient、component、attribute、entity IDをそのまま使います。
