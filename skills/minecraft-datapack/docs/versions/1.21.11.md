# Java Edition 1.21.11

data pack format 94.1。gamerule、environment attribute/timeline、loot、slot sourceが大きく変わります。

## metadata

94.1の機能を要求する単一バージョンのpack:

```json
{
  "pack": {
    "description": "1.21.11 data pack",
    "min_format": [94, 1],
    "max_format": [94, 1]
  }
}
```

`max_format: 94` はmajor 94の全minorを許すため、厳密固定とは異なります。

## コマンド

- `/stopwatch create|query|restart|remove`
- `/execute if|unless stopwatch <id> <range>`
- `/worldborder` 時間引数のdefaultを秒からtickへ。`s`, `d` suffix可
- gameruleをregistry化し、全名称をnamespaced snake_caseへ。例: `doDaylightCycle→minecraft:advance_time`, `doMobLoot→minecraft:mob_drops`, `commandBlocksEnabled→minecraft:command_blocks_work`

## JSON

- environment attributes と timeline。dimension/biomeの旧visual/gameplay fieldsをattributes/timelinesへ大移行
- `zombie_nautilus_variant`
- loot `filtered.modifier→on_pass/on_fail`、`discard`
- slot source と `minecraft:slots` loot entry
- component存在predicate
- item sprite atlasを `minecraft:items` へ分離

environment attributesのsource優先順位、modifier、補間、全fieldとtimeline trackは [`../reference/world-and-environment.md`](../reference/world-and-environment.md) を参照します。

## 互換性

custom dimension/biome、gamerule command、worldborder時間、filtered lootは手動移行必須です。

## JSONパラメータ差分

- **item**: item spriteをblocks atlasから`minecraft:items` atlasへ分離。component存在predicate、slot source、`minecraft:slots` loot entryを追加
- **dimension/worldgen**: dimension/biomeのvisual・gameplay fieldをenvironment attribute mapとtimelineへ移行。dimension typeに`attributes`、任意の`timelines`を追加し、`effects`を`skybox`/`cardinal_light`へ、`fixed_time`を`has_fixed_time`へ置換
- **enchantment**: effect component `minecraft:post_piercing_attack`、entity/location effect `apply_impulse`/`apply_exhaustion`、level value `exponent`、value effect `exponential`を追加。`play_sound.sound`はlevel別ID listも受け付ける
- **variant**: `zombie_nautilus_variant/`を追加し、`model`、`asset_id`、`spawn_conditions`で定義。既存variant familyは継承
- **predicate**: 全component typeに空objectによる存在predicateを追加し、entity flagsへ`is_in_water`と`is_fall_flying`を追加。値一致と存在だけの検査を区別
- **advancement**: kinetic weaponで単一use中にhitしたmob数を検査する`minecraft:spear_mobs` triggerを追加。その他のroot/criteria/reward schemaは1.21.10を継承
- **loot_table**: slot sourceと`minecraft:slots` pool entryを追加し、選択slotのitemをlootへ供給。既存root/pool fieldは継承
- **recipe**: ingredient、result、serializer集合は1.21.10を継承。固有の追加・変更・削除なし
- **item_modifier**: `minecraft:filtered`の`modifier`を`on_pass`/`on_fail`へ置換し、stackをemptyへする`minecraft:discard`を追加。旧fieldは手動移行
- **互換性**: custom dimension/biomeと旧effect field、旧`fixed_time`は手動移行。enchantmentの新typeとzombie nautilus entryは94.1以前では利用不可

## AI 生成規則

- camelCase gameruleを出力しない
- worldborderのbare時間を秒と解釈しない
- 94.1固有fieldを使う場合 `min_format:[94,1]`
- slot sourceはこのバージョンのinline/利用可能codecをreportで確認し、26.3以降のstandalone registry folderを先取りしない
