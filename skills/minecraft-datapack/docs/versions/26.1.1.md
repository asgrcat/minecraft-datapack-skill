# Java Edition 26.1.1

chat reporting等のhotfixです。26.1のデータパック/command/JSON仕様を継承します。

## JSONパラメータ差分

- **item**: 26.1のrecipe result、trade関連componentを継承。固有の追加・変更・削除なし
- **dimension/worldgen**: 26.1のworld clock、timeline、worldgen codecを継承。固有変更なし
- **enchantment**: 26.1のdefinition/effect/providerとloot function fieldを継承。固有変更なし
- **variant**: 26.1のadult/baby sound variant schemaを継承。固有変更なし
- **predicate**: 直接親26.1のcomponent/item/block/entity predicate schemaを継承。固有の追加・変更・削除なし
- **advancement**: 直接親26.1のroot、criteria、trigger、reward schemaを継承。固有の追加・変更・削除なし
- **loot_table**: 直接親26.1のroot、pool、entry、condition、function schemaを継承。固有の追加・変更・削除なし
- **recipe**: 直接親26.1の統一resultと拡張special recipe schemaを継承。固有の追加・変更・削除なし
- **item_modifier**: 直接親26.1のloot function schemaを継承。固有の追加・変更・削除なし
- **互換性**: data pack format 101.1と26.1の新save layoutを共有する

## AI 生成規則

format 101.1、world clock/trade、新save layoutを26.1と同一に扱います。
