# Java Edition 1.20

data pack format 15。sign NBT、advancement条件、loot conditionが破壊的に変わります。

## コマンド

- `/return <value>`。現在の function の残りtop-level行を停止して resultを返す
- `/data ... string` の境界に負数（末尾基準）

## JSON/NBT

- sign `Text1..Text4`, `Color`, `GlowingText` → `front_text`/`back_text` の `messages`, `filtered_messages`, `color`, `has_glowing_text`。top-level `is_waxed`
- advancement `placed_block`, `item_used_on_block`, `allay_drop_item_on_block` の複数fieldを `location` condition listへ
- advancement `recipe_crafted`、root `sends_telemetry_event`
- loot condition `alternative` → `any_of`、`all_of`
- loot function `reference`、loot table `random_sequence`
- smithing template/base/addition、trim/smithingをstable化
- structure processorの capped と block entity modifier

## 互換性

1.19.4の sign直接NBT操作、advancement trigger、`alternative` conditionは移行必須です。item component化はまだ1.20.5です。

## JSONパラメータ差分

- **item**: smithing template と armor trim を正式化したが、アイテムスタックは従来の NBT 形式を維持する。advancement の `placed_block`、`item_used_on_block`、`allay_drop_item_on_block` は複数の条件フィールドを削除して `location` の loot condition リストへ移行し、loot predicate の `alternative` は `any_of`／`all_of` に置換されたため、旧 predicate は書き換える。
- **dimension/worldgen**: structure processor に `capped` と block entity modifier を追加。その他の dimension/worldgen ルートは 1.19.4 を継承する。
- **enchantment**: 固定レジストリのままで単独のデータ駆動 JSON はなく、1.19.4 を継承する。armor trim は enchantment とは別形式である。
- **variant**: entity predicate の `type_specific` を含め 1.19.4 を継承し、このバージョン固有の variant レジストリ追加はない。
- **predicate**: loot condition `alternative` を `any_of` へrenameし、全termを満たす `all_of` を追加。standalone predicateとadvancement／loot内のinline conditionにも同じ変更が及ぶため、1.19.4の `alternative` は書き換える。
- **advancement**: rootへ任意boolean `sends_telemetry_event`、triggerへ `recipe_crafted` を追加。`placed_block`、`item_used_on_block`、`allay_drop_item_on_block` の旧 `block`／`item`／`state`／location predicate fieldを削除し、`location` のloot condition listへ統合したため旧conditionは非互換。
- **loot_table**: rootへ任意の `random_sequence` IDを追加し、指定時はworld seedとIDに基づく名前付き乱数列を使う。loot function `reference`、condition `any_of`／`all_of` を追加し、旧 `alternative` は削除されたため1.19.4定義をそのまま共用できない。
- **recipe**: `smithing_transform`、`smithing_trim`、`crafting_decorated_pot` を正式化。recipeのitemに `minecraft:air` は使えず、smithingの `template`／`base`／`addition` はingredient配列も受理するため、1.19.4の実験定義を正式リリースのschemaで再検証する。
- **item_modifier**: 別item modifierを `name` で呼ぶloot function `reference` を追加。conditionの `alternative` は `any_of` へ変更され `all_of` も利用可能になったため、旧condition付きmodifierは移行する。

## AI 生成規則

- `/return run` と `execute if function` は1.20では使わない
- front/back signのsideを明示する
- `update_1_20` feature flagを要求しないstable resourceを生成する
