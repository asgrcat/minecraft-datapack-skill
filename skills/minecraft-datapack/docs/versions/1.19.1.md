# Java Edition 1.19.1

pack format 10のまま chat component と `chat_type` が変わります。

## 変更

- raw JSON text の `clickEvent.run_command` 値は `/` 始まりが必須
- command から signed player chat を生成できない。system message は `/tellraw` 等を使う
- `chat_type` の system/game_info を削除し、chat/narration decoration 中心へ
- msg/team_msg を incoming/outgoing に分割
- `team_name` → `target`

## 互換性

1.19向け `chat_type` は形式警告なしで意味が変わります。chat resource を使う pack は必ず1.19.1用へ分離します。

## JSONパラメータ差分

- **item**: 1.19 の item JSON／NBT を継承し、このバージョン固有の追加・変更・削除はない。
- **dimension/worldgen**: 1.19 の dimension type、world preset、worldgen 定義を継承し、このバージョン固有の差分はない。
- **enchantment**: 固定レジストリのまま 1.19 を継承し、このバージョン固有の差分はない。
- **variant**: entity predicate の `type_specific` を含め 1.19 を継承し、このバージョン固有の差分はない。
- **predicate**: 1.19 の location／entity predicateを継承し、このバージョン固有の追加・変更・削除はない。旧 `feature` や旧entity専用fieldへ戻さない。
- **advancement**: 1.19 のtrigger集合とcondition形式を継承し、このバージョン固有の追加・変更・削除はない。1.19で削除された重複 `location` fieldは引き続き使用しない。
- **loot_table**: 1.19 のloot tableと `set_instrument` functionを継承し、このバージョン固有の追加・変更・削除はない。
- **recipe**: 1.19 のrecipe形式を継承し、このバージョン固有の追加・変更・削除はない。
- **item_modifier**: 1.19 のitem modifierと `set_instrument` を継承し、このバージョン固有の追加・変更・削除はない。
