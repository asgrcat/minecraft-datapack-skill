# Java Edition 1.14.4

形式4の最終バージョンです。

## 差分

- `server.properties` に `function-permission-level`
- `/reload` と `/forceload` を permission level 2 で利用可能に変更
- `/debug report` を追加
- function が本来許可されない `publish`/`debug` 等を実行できた問題を修正

## 互換性

専用 server では function の実行可能 command が設定依存です。管理 command を通常 pack の機能にしません。

## JSONパラメータ差分

- item: `inherits: 1.14.3`。item、recipe、lootのparameterにこのバージョン固有の追加・変更・削除はない
- dimension/worldgen: 1.14.3を継承し、custom registryは未対応
- enchantment: 1.14.3の固定registryとitem NBT形式を継承
- variant: 1.14.3を継承し、data-driven variant registryはない
- predicate: 1.14.3を継承し、独立resourceは未対応。このバージョン固有の追加・変更・削除はない
- advancement: 1.14.3のadvancement schemaを継承し、このバージョン固有の追加・変更・削除はない
- loot_table: 1.14.3のloot table schemaを継承し、このバージョン固有の追加・変更・削除はない
- recipe: 1.14.3のrecipe schemaを継承し、このバージョン固有の追加・変更・削除はない
- item_modifier: 1.14.3を継承し、独立resourceは未対応。このバージョン固有の追加・変更・削除はない

## AI 生成規則

1.15 の predicate/storage を使わず、1.14系の最終挙動を採用します。
