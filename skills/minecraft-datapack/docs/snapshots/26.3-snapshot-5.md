# Java Edition 26.3 Snapshot 5

data pack format 112.0。111.0で導入したelement list／tag codecを、inline値と参照の混在へ対応させます。

## metadata

```json
{
  "pack": {
    "description": "26.3-snapshot-5 data pack",
    "min_format": [112, 0],
    "max_format": [112, 0]
  }
}
```

## コマンド

26.3-snapshot-4のcommand差分を継承します。固有のcommand tree追加・削除はありません。

## JSON/NBT/registry

- element list／tag codecで、inline値とnamespaced ID参照の混在を許可
- `minecraft:sculk_patch` featureから `extra_rare_growths` と `catalyst_chance` を削除

## 互換性

111.0で拒否されたinline値と参照の混在listが112.0では有効です。ただし、同一resourceの循環参照が安全になったとはみなしません。

## JSONパラメータ差分

- **item**: 26.3-snapshot-4を継承。固有のcomponent追加・変更・削除なし
- **dimension/worldgen**: `sculk_patch.extra_rare_growths`と`catalyst_chance`を削除
- **enchantment**: element listでinline値と参照を混在可能。effect/provider集合は前スナップショットを継承
- **variant**: 26.3-snapshot-4を継承。固有の追加・変更・削除なし
- **predicate**: 複合predicate listでinline条件とID参照を混在可能
- **advancement**: predicate／loot table／recipe等のholder listでinline値と参照を混在可能
- **loot_table**: entry／modifier／number providerのlistでinline値と参照を混在可能
- **recipe**: holder listでinline値と参照を混在可能。serializer集合は前スナップショットを継承
- **item_modifier**: sequence等のlistでinline modifierとID参照を混在可能

## AI 生成規則

- 112.0より前へinline値と参照の混在listを逆輸入しない
- `sculk_patch`に削除済みfieldを出力しない
- 混在listの順序に意味がある場合は、参照展開後の評価順を機能テストする
- 自己参照・循環参照を生成しない
- 実験world以外へ適用しない
