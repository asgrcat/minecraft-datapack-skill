# Java Edition 26.3 Snapshot 6

data pack format 113.0。number provider参照のinline数値対応と、noise／density function schemaの大幅な変更が中心です。

## metadata

```json
{
  "pack": {
    "description": "26.3-snapshot-6 data pack",
    "min_format": [113, 0],
    "max_format": [113, 0]
  }
}
```

## コマンド

- `/publish` から `gamemode` 引数を削除
- world既定game modeは `/defaultgamemode`、player個別game modeは `/gamemode`を使用

## JSON/NBT/registry

- `cooking_fuel.burn_time`／`speed_multiplier`、`brewing_fuel.uses`／`speed_multiplier`、`compostable.layers`がinline数値も受付
- entity dataへ `invulnerable_time` tagを追加
- `minecraft:block_interact` loot contextへblock中央の `origin`を追加
- noiseの `firstOctave`→`base_octave`、`amplitudes`→`amplitude_modifiers`
- noiseに `base_amplitude`、`octave_count`、`normalize`を追加
- density functionに `pow`、`sqrt`、`log`、`sign`、`distance_to_point`、`slice`を追加
- `y_clamped_gradient`を汎用 `gradient`へrenameし、axis／tilingを追加
- `end_islands`を `end_outer_islands`へrename
- `feature_pool_element`が任意target nameのJigsawへ接続可能

## 互換性

112.0以前のnoise JSONは113.0へ移行して対象JARで地形を比較します。`normalize: "legacy"`は旧挙動の移行手段であり、新規noiseの既定として自動選択しません。

## JSONパラメータ差分

- **item**: cooking／brewing fuelとcompostableのnumber provider参照fieldがinline数値も受付
- **dimension/worldgen**: noise schemaを再編し、density function 5種と汎用gradient／sliceを追加。`end_islands`をrename
- **enchantment**: 26.3-snapshot-5を継承。固有の追加・変更・削除なし
- **variant**: 26.3-snapshot-5を継承。固有の追加・変更・削除なし
- **predicate**: 26.3-snapshot-5を継承。固有の追加・変更・削除なし
- **advancement**: 26.3-snapshot-5を継承。固有の追加・変更・削除なし
- **loot_table**: `minecraft:block_interact` contextへ`origin`を追加
- **recipe**: 26.3-snapshot-5のbrewingを含むserializer集合を継承。固有の追加・変更・削除なし
- **item_modifier**: 26.3-snapshot-5を継承。number providerを受けるfieldでは113.0のinline数値可否を対象codecで確認

## AI 生成規則

- `/publish`に削除済みの `gamemode`引数を出力しない
- inline数値を許可されたcomponent fieldと、number provider object／IDが必要なfieldを混同しない
- noiseに旧 `firstOctave`や`amplitudes`を出力しない
- `amplitude_modifiers`の要素数を`octave_count`と一致させる
- `sqrt`／`log`／`pow`のdomain外入力をdensity設計で処理する
- 既存worldではなく専用の実験worldと未生成chunkでworldgenを比較する
