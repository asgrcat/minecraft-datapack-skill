# Java Edition 26.3 Snapshot 2

data pack format 109.0。itemによるblock変換とworldgen feature／carverの再編が中心です。

## metadata

```json
{
  "pack": {
    "description": "26.3-snapshot-2 data pack",
    "min_format": [109, 0],
    "max_format": [109, 0]
  }
}
```

## コマンド

26.3-snapshot-1のcommand差分を継承します。固有のcommand tree追加・削除はありません。

## JSON/NBT/registry

- `minecraft:block_transformer` item componentを追加
- `minecraft:copy_properties_provider` block state providerを追加
- `basalt_columns` → `stepped_column_cluster`
- `basalt_pillar` → `single_block_pillar`
- `glowstone_blob` → `random_neighbor_spread`
- `minecraft:height_range` block predicateと `relative_to_sea_level` vertical anchorを追加
- `worldgen/configured_carver` を `worldgen/carver` へrename
- cave/canyon carverの `config` wrapperを除去してfieldをrootへ移動
- `minecraft:nether_cave` carverを削除し、`minecraft:cave`へ統合
- `minecraft:very_biased_to_bottom` int providerを追加

## 互換性

26.3-snapshot-1の旧feature type IDとcarver pathは109.0へ機械的に持ち込めません。rename後のtypeへ変えたうえで、新しい必須fieldを対象JARのvanilla dataから補います。

## JSONパラメータ差分

- **item**: block state provider、sound、particle、face制限、loot、drop方式、変換方式、消費／damageを持つ`minecraft:block_transformer`を追加
- **dimension/worldgen**: feature type 3種をrename・汎用化し、carver registry/pathとcave/canyon schemaを再編。block predicate、vertical anchor、int providerを追加
- **enchantment**: 26.3-snapshot-1を継承。固有の追加・変更・削除なし
- **variant**: 26.3-snapshot-1を継承。固有の追加・変更・削除なし
- **predicate**: `minecraft:height_range` block predicateを追加。entity／item predicateは前スナップショットを継承
- **advancement**: 26.3-snapshot-1を継承。固有の追加・変更・削除なし
- **loot_table**: `till/rooted_dirt` vanilla loot tableを追加。schema自体は前スナップショットを継承
- **recipe**: 26.3-snapshot-1を継承。固有の追加・変更・削除なし
- **item_modifier**: 26.3-snapshot-1を継承。固有の追加・変更・削除なし

## AI 生成規則

- `block_transformer`の任意fieldの既定値を推測で明示しない
- rename前の3 feature typeを出力しない
- `worldgen/configured_carver/`を作成しない
- cave/canyonに旧 `config` wrapper、`replaceable`、`lava_level`、`debug_settings`を残さない
- 実験world以外へ適用しない
