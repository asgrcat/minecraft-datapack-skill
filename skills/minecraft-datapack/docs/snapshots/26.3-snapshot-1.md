# Java Edition 26.3 Snapshot 1

26.3 の最初のスナップショットです。launcher ID は `26.3-snapshot-1`、data pack format は 108.0 です。

## metadata

```json
{
  "pack": {
    "description": "26.3-snapshot-1 data pack",
    "min_format": [108, 0],
    "max_format": [108, 0]
  }
}
```

## コマンド

- `/give`、`/tick step`、`/tick sprint stop` は失敗を command error として通知
- `/team join|leave` の result を、実際に team が変化した entity 数へ変更
- `/item` と `execute if|unless items` の slot 引数を slot source 化
- `/item ... from entity` の entity selector は複数 entity を許可
- `tellraw` の NBT text component 解決回数を 64K に制限

## JSON/NBT/registry

- `slot_source/` をデータパック resource として追加し、`minecraft:reference` と `minecraft:slot_range` を利用可能
- `minecraft:provides_pottery_pattern` item componentを追加
- `minecraft:pot_decorations` と decorated pot の `sherds` を4方向の item stack mapへ変更
- `trim_material.asset_name` を `palette` へ置換し、`override_armor_assets` を削除
- `instrument.durability_damage` を追加し、`use_duration: 0` を許可
- `worldgen/configured_feature` を `worldgen/feature` へ移動し、旧 `config` wrapperをrootへinline化
- `worldgen/material_rule/` と `worldgen/material_condition/` registryを追加
- noise settings の `surface_rule` を `material_rule` へrename
- `minecraft:dimension_origin` structure placement、複数のfeature／rule testを追加

## 互換性

26.2のconfigured feature、surface rule、decorated pot、trim material、slot指定をそのまま読み込ませません。特に `/item` の単一slot前提の置換結果と、複数slot sourceの結果を混同しないでください。

## JSONパラメータ差分

- **item**: `provides_pottery_pattern`を追加。`pot_decorations`を4方向item stack mapへ変更し、inline trim materialの`asset_name`を`palette`へrename
- **dimension/worldgen**: configured featureを`worldgen/feature`へ移し`config`をinline化。material rule／condition registryと`dimension_origin`を追加
- **enchantment**: 26.2のdefinition/effect/provider集合を継承。固有の追加・変更・削除なし
- **variant**: 26.2のvariant registryを継承。固有の追加・変更・削除なし
- **predicate**: 26.2のentity component-map形式を継承。`execute if|unless items`はslot sourceを受け取る
- **advancement**: 26.2のroot/trigger形式を継承。固有の追加・変更・削除なし
- **loot_table**: `minecraft:command_slot_source` contextを追加。既存entry/function schemaは26.2を継承
- **recipe**: 26.2のrecipe schemaを継承。固有の追加・変更・削除なし
- **item_modifier**: 26.2のfunction集合を継承。slot source参照先とitem stack componentの変更を反映

## AI 生成規則

- `26.3` や `snapshot-1` を launcher ID の代わりに出力しない
- configured featureに旧 `config` wrapperを出力しない
- `minecraft:pot_decorations`を4個のitem ID配列として出力しない
- `/item` のslot sourceが複数slot／複数entityを返す可能性を考慮する
- 実験world以外へ適用しない
