# Java Edition 26.3 Snapshot 7

data pack format 115.0。block state表現、item animation component、exploration map生成、density functionの数値精度が変更されます。

## metadata

```json
{
  "pack": {
    "description": "26.3-snapshot-7 data pack",
    "min_format": [115, 0],
    "max_format": [115, 0]
  }
}
```

## コマンド

- `/swing`はplayerへ使ってもattack strengthをresetしない
- `/swing`へ任意のanimation type `whack`／`stab`と、正のtime値によるdurationを追加
- animation type省略時は`whack`、duration省略時は`6t`

115.0の`commands.json`では `/swing [<targets> [mainhand|offhand [<animation> [<duration>]]]]` の順です。

## JSON/NBT/registry

- block state objectの`Name`を`id`、`Properties`を`properties`へrename
- blockのdefault stateはblock ID文字列だけのcompact formでも参照可能
- item componentに`minecraft:attack_animation`と`minecraft:interact_animation`を追加
  - どちらも`type`（`whack`／`stab`）と正のinteger `duration`（tick）を持つ
- `minecraft:swing_animation`を削除し、attack用とinteraction用の2 componentへ分割
- `minecraft:map_color` item componentを削除
- `minecraft:exploration_map` loot functionから`map_color`を削除し、入力itemのtypeを変更せずmap dataだけを追加する形へ変更
- density functionとnoiseの全中間計算をdouble precisionからsingle precisionへ変更
- block／item tag `#minecraft:concrete_stairs`、`#minecraft:concrete_slabs`を追加
- item tag `#minecraft:extendable_maps`を追加
- Mojang記事は`#minecraft:cloneable_maps`も列挙するが、Snapshot 7公式server JARのgenerated dataと内蔵dataには該当tagがないため、利用可能とは扱わない

## 互換性

113.0以前のblock state object、animation component、exploration map生成は115.0へそのまま持ち込めません。`minecraft:exploration_map`を使うloot entry／villager tradeは、出力itemを`minecraft:map`から`minecraft:filled_map`または目的のexplorer map itemへ変更します。構造が見つからない場合は`minecraft:map_id`なしのitemが残るため、vanillaと同様に`minecraft:filtered`と`minecraft:discard`で除外します。

single precision化は同じdensity function JSONでも地形を変える可能性があります。既存worldではなく、Snapshot 7専用worldの未生成chunkで比較します。

## JSONパラメータ差分

- **item**: `attack_animation`／`interact_animation`を追加し、`swing_animation`／`map_color`を削除
- **dimension/worldgen**: block state fieldをlowercaseへrenameしcompact formを追加。density function／noiseをsingle precision化
- **enchantment**: 26.3-snapshot-6を継承。固有の追加・変更・削除なし
- **variant**: 26.3-snapshot-6を継承。固有の追加・変更・削除なし
- **predicate**: 26.3-snapshot-6を継承。固有のcondition追加・変更・削除なし
- **advancement**: 26.3-snapshot-6を継承。固有のtrigger／condition追加・変更・削除なし
- **loot_table**: `exploration_map.map_color`を削除し、function適用前後のitem typeを同一に変更
- **recipe**: map extensionの対象を`#minecraft:extendable_maps`で制御。記事にある`#minecraft:cloneable_maps`は公式JARに存在しない
- **item_modifier**: `exploration_map`の変更をloot tableと同様に適用

## AI 生成規則

- block state objectへ旧`Name`／`Properties`を出力しない
- `minecraft:swing_animation`や`minecraft:map_color`を出力しない
- attackとinteractionの両方を同じanimationにする場合も、2つのcomponentを明示する
- animationの`duration`へ0以下を出力しない
- `minecraft:exploration_map`に`map_color`を出力せず、loot entry側で生成するmap itemを選ぶ
- exploration mapの探索失敗時に`minecraft:map_id`なしのitemを配布しない
- `#minecraft:cloneable_maps`をSnapshot 7で存在確認済みのtagとして出力しない
- 113.0以前と同じworldgen結果を浮動小数点roundingへ依存して保証しない
- Snapshot 7の公式JARでcommand report、reload、未生成chunkの地形を再検証する
