# Java Edition 26.3 Snapshot 3

data pack format 110.0。`/posteffect`、number provider registry、データ駆動brewing recipeを追加します。

## metadata

```json
{
  "pack": {
    "description": "26.3-snapshot-3 data pack",
    "min_format": [110, 0],
    "max_format": [110, 0]
  }
}
```

## コマンド

- `/posteffect add|clear|list|remove` を追加
- `/place feature` がinline feature定義を受理
- post effect本体はresource pack側にあり、serverはclientでの適用成否を確認できない

## JSON/NBT/registry

- `minecraft:gameplay/bed_rule.explodes` を `destroy_on_use` へrenameし、`destroy_on_leave`を追加
- `minecraft:gameplay/straw_bed_rule` environment attributeを追加
- `minecraft:block_transformer.update_from_neighbors`を追加
- `minecraft:compostable` item componentを追加
- `minecraft:mob_effects` component predicateがeffect listの件数、全体size、effectごとのduration／amplifier／ambient／visibleを照合可能
- `minecraft:number_provider` registryを追加
- `minecraft:number_dispatcher`、`conditional_value`、`weighted_list`を追加
- `minecraft:brewing` recipeをデータ駆動化
- coral／kelp／seagrass／sea pickleの専用feature typeを削除
- `minecraft:cuboid`、`minecraft:random_chance` placement modifier等を追加
- item tag `#dowses_campfires` を `#douses_campfires` へ修正

## 互換性

109.0のbed rule、旧tag名、削除されたfeature typeを110.0へ残しません。custom brewing recipeは通常crafting recipeとslot・contextが異なるため、`/recipe`の付与対象として仮定しないでください。

## JSONパラメータ差分

- **item**: `compostable`を追加し、`block_transformer.update_from_neighbors`を追加
- **dimension/worldgen**: bed ruleをrename・拡張。専用feature type 4種を削除し、placement modifier／providerを追加
- **enchantment**: 26.3-snapshot-2を継承。固有の追加・変更・削除なし
- **variant**: 26.3-snapshot-2を継承。固有の追加・変更・削除なし
- **predicate**: `minecraft:mob_effects` component predicateを件数／size／effect別propertyで拡張し、number provider内の条件参照に使用可能
- **advancement**: 26.3-snapshot-2を継承。固有の追加・変更・削除なし
- **loot_table**: Silk Touch／Shears判定のvanilla predicate参照を共通化。root schemaは前スナップショットを継承
- **recipe**: `minecraft:brewing`を追加し、input／reagentのpotion ingredientとoutput item stackを定義可能
- **item_modifier**: number provider registry追加の影響を受けるが、function集合は前スナップショットを継承

## AI 生成規則

- `/posteffect`をresource packなしで表示保証できる機能として説明しない
- bed ruleに旧 `explodes`を出力しない
- `minecraft:compostable.layers`には110.0時点でnumber provider IDを使う
- brewing recipeをcrafting recipeのingredient/result形で生成しない
- 削除された専用feature typeを出力しない
- 実験world以外へ適用しない
