# Java Edition 26.3 Snapshot 8

data pack format 116.0。desert wellのデータ駆動化、placement modifierとblock predicateの追加、Explorer Map item IDのrenameが行われます。

## metadata

```json
{
  "pack": {
    "description": "26.3-snapshot-8 data pack",
    "min_format": [116, 0],
    "max_format": [116, 0]
  }
}
```

## コマンド

26.3-snapshot-7のcommand差分を継承します。Snapshot 7とSnapshot 8の公式server JARが生成した`commands.json`は同一で、固有のcommand tree追加・変更・削除はありません。

## JSON/NBT/registry

- feature type `minecraft:desert_well`を削除
  - vanillaの`worldgen/feature/desert_well`は`minecraft:overlay`、`minecraft:template`、placement modifier、block predicateの組合せへ移行
- `minecraft:template` featureへ`processors`を追加
  - structure processor listのnamespaced IDまたはinline定義を受ける
- placement modifier `minecraft:randomly_selected`を追加
  - `placements`は選択対象となるplacement modifierの空でないlist
- block predicate `minecraft:volume_match`を追加
  - `min`／`max`は判定位置からのoffsetを表す、各要素が-16〜16のinteger 3要素list
  - `match`はvolume内の全blockへ適用するblock predicate
- Explorer Map item IDをrename
  - `minecraft:ancient_city_map` → `minecraft:buried_ancient_city_map`
  - `minecraft:mineshaft_map` → `minecraft:buried_mineshaft_map`
  - `minecraft:abandoned_campsite_map` → `minecraft:abandoned_camp_map`
- item tag `#minecraft:clonable_maps`のentryをrename後の3 IDへ更新
- 公式JARの全vanilla biome JSONでは、`minecraft:gameplay/natural_mob_spawns`を直接値から`modifier: "overlay"`と`argument`を持つ展開形へ変更
- Abandoned Campの`minecraft:random_spread.spacing`を34から37へ変更
- 全色のConcrete Stairs／SlabsについてConcreteからのstonecutting recipeとrecipe advancementを追加

## 互換性

115.0の`minecraft:desert_well` feature typeは116.0に存在しません。custom desert wellは、vanillaの116.0実装と同様にtemplate resource、`minecraft:template` feature、processor list、placement、block predicateへ分解します。`processors`を使う場合は、処理後のblock stateとblock entity lootが意図どおりかを未生成chunkで検証します。

旧Explorer Map item IDをloot table、item tag、recipe、predicate、tradeへ残すと116.0のregistry参照を解決できません。rename後のIDへ一括して移行し、item tag名は公式JARに存在する綴りの`#minecraft:clonable_maps`を使います。

Snapshot 8のvanilla biomeと同じspawn list合成を意図する場合、`natural_mob_spawns`へ直接値を出力せず`overlay` modifierを明示します。直接値はoverrideとして扱われるため、親environmentのspawn設定を置換する意味になります。

## JSONパラメータ差分

- **item**: Explorer Map 3種のitem IDをrename。`#minecraft:clonable_maps`もrename後のIDへ更新
- **dimension/worldgen**: `desert_well` feature typeを削除。`template.processors`、`randomly_selected` placement modifier、`volume_match` block predicateを追加。vanilla biomeの`natural_mob_spawns`をexplicit overlay化
- **enchantment**: 26.3-snapshot-7を継承。固有の追加・変更・削除なし
- **variant**: 26.3-snapshot-7を継承。固有の追加・変更・削除なし
- **predicate**: item／entity predicateのcondition集合は26.3-snapshot-7を継承。worldgen block predicateへ`volume_match`を追加
- **advancement**: Concrete Stairs／Slabsのstonecutting recipe advancementを追加。trigger／condition schema固有の変更なし
- **loot_table**: Abandoned Camp lootのExplorer Map item IDと表示名translation keyを更新。function／condition schema固有の変更なし
- **recipe**: 全色のConcrete Stairs／Slabsへstonecutting recipeを追加。serializer schema固有の変更なし
- **item_modifier**: 26.3-snapshot-7を継承。固有のfunction追加・変更・削除なし

## AI 生成規則

- data pack formatを116.0へ固定し、115.0以前のfeature／item IDを推測で持ち込まない
- feature type `minecraft:desert_well`を出力しない
- `minecraft:template.processors`にはstructure processor listのIDまたはinline定義だけを出力する
- `minecraft:randomly_selected.placements`へ空listを出力しない
- `minecraft:volume_match`の`min`／`max`を3要素かつ-16〜16のinteger listにし、`match`を省略しない
- 旧`ancient_city_map`／`mineshaft_map`／`abandoned_campsite_map` item IDを出力しない
- map tagを`#minecraft:cloneable_maps`と綴らず、公式JARに存在する`#minecraft:clonable_maps`を使う
- vanilla相当のbiome spawn合成では`natural_mob_spawns`へ`modifier: "overlay"`と`argument`を明示する
- Snapshot 8の公式JARでcommand report、registry、vanilla data、reload、未生成chunkのworldgenを再検証する
