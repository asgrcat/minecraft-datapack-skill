# Java Edition 1.14.4

形式4の最終バージョンです。

## 差分

- `server.properties` に `function-permission-level`
- `/reload` と `/forceload` を permission level 2 で利用可能に変更
- `/debug report` を追加
- function が本来許可されない `publish`/`debug` 等を実行できた問題を修正

## 互換性

専用 server では function の実行可能 command が設定依存です。管理 command を通常 pack の機能にしません。

## AI 生成規則

1.15 の predicate/storage を使わず、1.14系の最終挙動を採用します。
