# Java Edition 1.21.2

data pack format 57。item component、recipe ingredient、entity/attribute IDを再編します。

## コマンド

- `/rotate <target> <rotation>` または `facing ...`

## entity/attribute

- boat/chest boatを木種別のentity IDへ分割
- attribute IDの `generic.`, `player.`, `zombie.` prefixを削除
- `fire_resistant` component → `damage_resistant`
- container `Lock` → `lock`、値はitem predicate

## item/recipe JSON

- `consumable`, `equippable`, `glider`, `enchantable`, `repairable`, `use_cooldown`, `use_remainder`, `death_protection`, `item_model` 等
- `food` はnutrition data、食べる動作は `consumable`
- ingredient `{"item":"x"}` → `"x"`、`{"tag":"t"}` → `"#t"`
- `crafting_transmute`
- `instrument`, `trial_spawner` registry
- advancement `killed_by_crossbow→killed_by_arrow`
- enchantment effect `damage_item→change_item_damage`

## JSONパラメータ差分

- **item**: `consumable`、`equippable`、`glider`、`enchantable`、`repairable`、`use_cooldown`、`use_remainder`、`death_protection`、`item_model`等を追加。`food`をnutritionへ限定し、使用動作を`consumable`へ分離。`fire_resistant`を`damage_resistant`へrename
- **dimension/worldgen**: 1.21.1のdimension/worldgen schemaを継承。`instrument/`と`trial_spawner/`は追加registryだがdimension/worldgen definitionではない
- **enchantment**: entity/location effect type `minecraft:damage_item`を`minecraft:change_item_damage`へrenameし、負数によるitem修復を許可。`projectile_spawned`の適用対象を拡張
- **variant**: painting definitionへ任意のtext component `author`、`title`を追加。wolf variant schemaは変更なし
- **predicate**: item/component predicateは`fire_resistant→damage_resistant`等のcomponent renameと新component型へ追従。containerの`lock`は文字列でなくitem predicateを取る
- **advancement**: trigger `minecraft:killed_by_crossbow`を`minecraft:killed_by_arrow`へrenameし、crossbow以外のarrow killも対象化。その他のroot/criteria schemaは1.21.1を継承
- **loot_table**: root/pool/entry/function schemaは1.21.1を継承するが、condition内のitem/component predicateは1.21.2のcomponent IDと型へ更新
- **recipe**: ingredientを`{"item":"x"}`/`{"tag":"t"}`から`"x"`/`"#t"`へ変更し、入力stackのcomponentを保持してitem typeを変換する`minecraft:crafting_transmute`を追加
- **item_modifier**: function list/root schemaは1.21.1を継承するが、componentを読む・書くfunction値は1.21.2の追加・rename後component codecへ更新
- **互換性**: 旧effect typeと旧component ID、object形式recipe ingredientは移行が必要

## AI 生成規則

- old attribute prefix、generic boat+Type、object ingredientを使わない
- componentを1.21.2のexact registryへ制限
- 1.21.3はhotfixなので同仕様を共有できる
