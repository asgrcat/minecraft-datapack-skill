# Java Edition 26.1

ゲームバージョン番号が年ベースへ移った最初の正式リリースです。data pack format 101.1。

## コマンド

- `/swing [target] [mainhand|offhand]`
- villager/piglin inventory slotは `mob.inventory.*`。旧 `villager.*`, `piglin.*` を削除
- `/time [of <clock>] set|add|pause|resume|rate|query ...`
- time set/add resultはcurrent day timeでなく総elapsed ticks
- `/fetchprofile entity`

## JSON

- `world_clock/<id>.json` と timelineの必須 `clock`、`time_markers`
- `villager_trade`, `trade_set` とtagでvillager/wandering trader tradeをデータ駆動化
- `pig_sound_variant`, `cat_sound_variant`, `cow_sound_variant`, `chicken_sound_variant` registry。wolf soundも `adult_sounds`/`baby_sounds` wrapperへ
- recipe `result` をIDまたは `{id,count,components}` に統一。smelting系もcount
- bone meal featureをデータ駆動化

world clock、timeline、time markerの全パラメータは [`../reference/world-and-environment.md`](../reference/world-and-environment.md)、tradeとsound variantは [`../reference/registry-formats.md`](../reference/registry-formats.md) を参照します。

## world storage

Overworldも `dimensions/minecraft/overworld`、player dataを `players/`、shared dataをnamespace化する等、save layoutを大改編。26.1で開いたworldのdowngradeを行いません。

## JSONパラメータ差分

- **item**: recipe `result`をitem IDまたは`{id,count,components}`へ統一し、smelting系でも`count`を許可。`minecraft:dye`、`minecraft:additional_trade_cost` componentを追加
- **dimension/worldgen**: `world_clock/`を追加し、timelineの`clock`を必須化、任意の`time_markers`を追加。bone meal featureをデータ駆動化し、time依存処理はdimensionのdefault clockを考慮
- **enchantment**: definition/effect/provider registryは1.21.11を継承。`enchant_randomly`/`enchant_with_levels`へ任意の`include_additional_cost_component`を追加し、data-driven tradeからのitem生成に利用
- **variant**: `cat_sound_variant`、`pig_sound_variant`、`cow_sound_variant`、`chicken_sound_variant`を追加。wolf sound fieldsを`adult_sounds`へ移し、`baby_sounds`を追加。cow sound variantはflat fieldsを使う
- **predicate**: `environment_attribute_check` condition、`time_check.clock`、player sub-predicateの`food`を追加。1.21.11のcomponent存在、item/block/entity predicate schemaも継承
- **advancement**: 1.21.11の`spear_mobs`を含むroot、criteria、trigger、reward schemaを継承。固有の追加・変更・削除なし
- **loot_table**: root/pool/entry/condition schemaは1.21.11を継承。`enchant_randomly`/`enchant_with_levels`に任意の`include_additional_cost_component`を追加
- **recipe**: 全serializerの`result`をitem IDまたは`{id,count,components}`へ統一し、smelting系でもcountを許可。主要typeへ`show_notification`を拡張し、transmuteと複数special recipeのingredient/resultを設定可能化
- **item_modifier**: 1.21.11の`filtered`/`discard`を継承し、`enchant_randomly`/`enchant_with_levels`へ任意の`include_additional_cost_component`を追加
- **互換性**: 旧wolf soundのflat object、clockなしtimeline、recipe resultの旧union formは移行が必要。26.1 worldはdowngrade非対応

## AI 生成規則

- `26.1` を `1.26.1` と解釈しない
- time commandは必ずclockと新result semanticsを考慮
- trade/sound/recipeは26.1 vanilla dataを基底にする
- runtime検証はJava 25
