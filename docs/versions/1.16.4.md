# Java Edition 1.16.4

social interactions と不具合修正が中心で、データパック/command/JSON の authoring 仕様変更はありません。

## JSONパラメータ差分

- item: `inherits: 1.16.3`。item、recipe、loot、predicate parameterにこの版固有の変更はない
- dimension/worldgen: 1.16.3のexperimental worldgen schemaを継承し、この版固有の変更はない
- enchantment: 1.16.3の固定registryとitem NBT形式を継承
- variant: 1.16.3を継承し、data-driven variant registryはない
- predicate: 1.16.3のpredicate schemaを継承し、この版固有の追加・変更・削除はない
- advancement: 1.16.3のadvancement schemaを継承し、この版固有の追加・変更・削除はない
- loot_table: 1.16.3のloot table schemaを継承し、この版固有の追加・変更・削除はない
- recipe: 1.16.3のrecipe schemaを継承し、この版固有の追加・変更・削除はない
- item_modifier: 1.16.3を継承し、独立resourceは未対応。この版固有の追加・変更・削除はない

## AI 生成規則

1.16.3を継承します。公式記事の地域表示日ではなく正式リリース日 2020-11-02 をバージョン識別に使います。
