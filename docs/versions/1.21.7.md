# Java Edition 1.21.7

data pack format 81。一般command/JSON schemaの大変更はなく、vanilla resource追加が中心です。

## 差分

- painting `minecraft:dennis` と placeable tag更新
- Lava Chicken music disc、loot/sound resource
- release candidateでpack format increment漏れを修正したため正式リリースは81

## JSONパラメータ差分

- **item**: Lava Chicken music discと`jukebox_playable`参照先を追加。item component schema自体は1.21.6を継承
- **dimension/worldgen**: 1.21.6のdimension/worldgen codecを継承。固有変更なし
- **enchantment**: 1.21.6のdefinition/effect/provider schemaを継承。固有変更なし
- **variant**: painting variant `minecraft:dennis`を追加し、`painting_variant/placeable` tagを更新。painting definitionのfield構造は変更なし
- **predicate**: 1.21.6のstrict predicate schemaを継承。固有のparameter追加・変更・削除なし
- **advancement**: 1.21.6の`player_sheared_equipment`を含むstrict advancement schemaを継承。固有のparameter変更なし
- **loot_table**: 1.21.6のstrict loot schemaを継承。Lava Chicken関連のvanilla loot resourceは追加されるがparameter構造の変更なし
- **recipe**: 1.21.6のstrict ingredient/result/serializer schemaを継承。固有の追加・変更・削除なし
- **item_modifier**: 1.21.6のstrict loot function schemaを継承。固有の追加・変更・削除なし
- **互換性**: 新IDへ依存するpackの最小versionは1.21.7。既存1.21.6 JSONの構造移行は不要

## AI 生成規則

1.21.6のstrict JSON/dialog仕様を継承し、新vanilla IDを使う場合だけ最小バージョンを1.21.7とします。
