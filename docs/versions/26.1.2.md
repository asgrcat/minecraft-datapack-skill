# Java Edition 26.1.2

spectator attack等のhotfixです。データパックauthoring仕様は26.1.1を継承します。

## JSONパラメータ差分

- **item**: 26.1.1のitem/recipe/trade schemaを継承。固有の追加・変更・削除なし
- **dimension/worldgen**: 26.1.1のworld clock、timeline、worldgen codecを継承。固有変更なし
- **enchantment**: 26.1.1のdefinition/effect/provider schemaを継承。固有変更なし
- **variant**: 26.1.1のvisual/sound variant schemaを継承。固有変更なし
- **predicate**: 直接親26.1.1のcomponent/item/block/entity predicate schemaを継承。固有の追加・変更・削除なし
- **advancement**: 直接親26.1.1のroot、criteria、trigger、reward schemaを継承。固有の追加・変更・削除なし
- **loot_table**: 直接親26.1.1のroot、pool、entry、condition、function schemaを継承。固有の追加・変更・削除なし
- **recipe**: 直接親26.1.1の統一resultとspecial recipe schemaを継承。固有の追加・変更・削除なし
- **item_modifier**: 直接親26.1.1のloot function schemaを継承。固有の追加・変更・削除なし
- **互換性**: data pack format 101.1を共有する。26.2のentity predicate component mapは使用不可

## AI 生成規則

101.1の最終正式リリースとして26.1のcommand/JSON profileを使い、26.2のentity predicateを先取りしません。
