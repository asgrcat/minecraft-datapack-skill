# Java Edition 1.19.4

data pack format 12。damage type registry と command拡張が中心です。

## コマンド

- `/damage`, `/ride`
- dimensionを指定する `/clone ... from|to <dimension>`
- `/data modify ... string ... [start] [end]`
- `/effect ... infinite`
- `/execute if|unless loaded|dimension`, `on <relation>`, `positioned over`, `summon`
- `/title times`, `/weather` が `t|s|d` suffix対応。旧 bare weather値は tick解釈なので秒を維持するなら `s`

## JSON

- `data/<namespace>/damage_type/<id>.json`。必須 `message_id`, `exhaustion`, `scaling`
- damage source predicate の旧 boolean群を削除し `tags:[{id,expected}]`
- biome `precipitation` string → `has_precipitation` boolean
- recipe `show_notification`
- translatable textに `fallback`
- display/interaction entity

## experimental

trim/smithing の1.20 resourceはこのバージョンでは `update_1_20` experimentです。stable仕様へ混ぜません。

## AI 生成規則

- custom damageの挙動はdamage type JSONだけでなくdamage type tagで定義する
- 1.20 sign/advancement schemaを先取りしない
