# Java Edition 1.19.4

data pack format 12。damage type registry と command拡張が中心です。

## コマンド

- `/damage`, `/ride`
- dimensionを指定する `/clone ... from|to <dimension>`
- `/data modify ... string ... [start] [end]`
- `/effect ... infinite`
- `/execute if|unless loaded|dimension`, `on <relation>`, `positioned over`, `summon`
- `/title times`, `/weather` が `t|s|d` suffix対応。旧 bare weather値は tick解釈なので秒を維持するなら `s`

## JSON

- `data/<namespace>/damage_type/<id>.json`。必須 `message_id`, `exhaustion`, `scaling`
- damage source predicate の旧 boolean群を削除し `tags:[{id,expected}]`
- biome `precipitation` string → `has_precipitation` boolean
- recipe `show_notification`
- translatable textに `fallback`
- display/interaction entity

## experimental

trim/smithing の1.20 resourceはこのバージョンでは `update_1_20` experimentです。stable仕様へ混ぜません。

## JSONパラメータ差分

- **item**: recipe に `show_notification` を追加。アイテムスタック本体は 1.19.3 の NBT 形式を継承する。
- **dimension/worldgen**: biome JSON の文字列 `precipitation` を削除し、真偽値 `has_precipitation` に置換。旧キーのままの biome は移植時に書き換える。その他の dimension/worldgen 定義は 1.19.3 を継承する。
- **enchantment**: 固定レジストリのまま 1.19.3 を継承し、このバージョン固有の JSON 差分はない。
- **variant**: `type_specific` を含む entity predicate は 1.19.3 を継承し、このバージョン固有の variant レジストリ追加はない。
- **predicate**: damage source predicateから `is_projectile`、`is_explosion`、`bypasses_armor`、`bypasses_invulnerability`、`bypasses_magic`、`is_fire`、`is_magic`、`is_lightning` を削除し、`tags:[{id,expected}]` に置換。旧boolean群を含むpredicateは移行必須。
- **advancement**: rootとtrigger集合は1.19.3を継承するが、damage source predicateを内包するcombat系conditionは新しい `tags` 形式へ更新する。旧boolean群を残したadvancementは1.19.4互換ではない。
- **loot_table**: loot tableのrootとentryは1.19.3を継承する。`damage_source_properties` 等で使うdamage source predicateは `tags:[{id,expected}]` へ移行し、data-driven damage typeの性質はdamage type tagで判定する。
- **recipe**: 任意boolean `show_notification` を追加し、未指定時は `true`。update_1_20実験下では `smithing_transform`、`smithing_trim`、`crafting_decorated_pot` も追加されたため、実験flagなしの1.19.3向けpackと共用しない。
- **item_modifier**: function形式は1.19.3を継承する。modifierのconditionにdamage source predicateを置く場合は旧boolean群を削除して `tags` へ移行し、それ以外の固有function追加・削除はない。

## AI 生成規則

- custom damageの挙動はdamage type JSONだけでなくdamage type tagで定義する
- 1.20 sign/advancement schemaを先取りしない
