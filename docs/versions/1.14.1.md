# Java Edition 1.14.1

新しい authoring schema はありませんが、function の実行順を仕様どおりに直した重要な修正版です。

## 修正

- nested function の実行順が逆転する不具合を修正
- function tag の順序が reload 間で不定、かつ data pack priority を無視する不具合を修正
- `/tp` が destination entity ではなく context dimension を使う不具合を修正
- selector 順序の不安定さを修正

## 互換性

バグに依存して逆順で動いていた1.14 pack は順序が変わります。tag の配列順を意図した実行順として明示してください。

## AI 生成規則

function/tag の順序は JSON 配列順を正として生成し、1.14の逆順バグを再現しません。
