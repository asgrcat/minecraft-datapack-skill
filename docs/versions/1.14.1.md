# Java Edition 1.14.1

新しい authoring schema はありませんが、function の実行順を仕様どおりに直した重要な修正リリースです。

## 修正

- nested function の実行順が逆転する不具合を修正
- function tag の順序が reload 間で不定、かつ data pack priority を無視する不具合を修正
- `/tp` が destination entity ではなく context dimension を使う不具合を修正
- selector 順序の不安定さを修正

## 互換性

バグに依存して逆順で動いていた1.14 pack は順序が変わります。tag の配列順を意図した実行順として明示してください。

## JSONパラメータ差分

- item: `inherits: 1.14`。item、recipe、lootのparameterにこのバージョン固有の追加・変更・削除はない
- dimension/worldgen: 1.14を継承し、custom registryは未対応
- enchantment: 1.14の固定registryとitem NBT形式を継承
- variant: 1.14を継承し、data-driven variant registryはない
- predicate: 1.14を継承し、独立resourceは未対応。このバージョン固有の追加・変更・削除はない
- advancement: 1.14のadvancement schemaを継承し、このバージョン固有の追加・変更・削除はない
- loot_table: 1.14の再編後schemaを継承し、このバージョン固有の追加・変更・削除はない
- recipe: 1.14のrecipe schemaを継承し、このバージョン固有の追加・変更・削除はない
- item_modifier: 1.14を継承し、独立resourceは未対応。このバージョン固有の追加・変更・削除はない

## AI 生成規則

function/tag の順序は JSON 配列順を正として生成し、1.14の逆順バグを再現しません。
