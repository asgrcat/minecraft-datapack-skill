# Java Edition 1.18

data pack format 8。高さと terrain generation の全面変更を含みます。

## コマンドと runtime

- `/jfr`
- 最低 Java 17
- scoreboard objective/holder/team 名の長さ制限を撤廃

## JSON/NBT

- loot `set_contents`, `set_loot_table` に block entity ID の `type` が必須
- loot function `set_potion {id:<potion>}`
- advancement trigger `fall_from_height`, `ride_entity_in_lava`
- `nether_travel.entered` → `start_position`、`exited` を削除
- Spawner `SpawnPotentials` を `{weight,data}`、`SpawnData` の内容を `SpawnData.entity` へ
- world height、noise、biome/terrain generation を全面改訂

## 互換性

custom worldgen は1.17から移植せず、1.18 server JARの `--reports --server` 出力と比較します。loot table の block entity type 欠落は load error になり得ます。

## AI 生成規則

- worldgen JSON は1.18 vanilla dataを基底にする
- 1.18.2の density/structure/tag schemaを先取りしない
