# Java Edition 1.15.2

## 差分

- gamerule `doPatrolSpawning`, `doTraderSpawning`
- F3+T が loot table/advancement まで誤って reload していた問題を修正。data pack の再読込は `/reload` を使う
- authoring schema の追加はありません
