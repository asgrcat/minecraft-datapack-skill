# Java Edition 1.21

data pack format 48。legacy data folderを原則単数形へrenameし、enchantment等をデータ駆動化します。

## folder rename

```text
advancements     → advancement
functions        → function
item_modifiers   → item_modifier
loot_tables      → loot_table
predicates       → predicate
recipes          → recipe
structures       → structure
tags/functions   → tags/function
tags/items       → tags/item
tags/blocks      → tags/block
```

他のregistry tag folderも単数形です。

## JSON

- `painting_variant`, `jukebox_song`, `enchantment`, `enchantment_provider` registry
- data-driven enchantmentのproperties/effects/conditions、availability/exclusivity tag
- `fixed_placement` placement modifier
- jukebox song/painting resource

## コマンド/NBT

- `@n` nearest entity selector
- attribute modifierの UUID+nameをnamespaced `id` 1つへ
- item argumentで `!component` によるdefault component削除
- entity/item attribute NBTを `id/base/modifiers/operation` の新形式へ

## 互換性

旧複数形folderは移動必須です。1.20.6との複数版対応はoverlayでfolder treeを分けます。

## AI 生成規則

- 1.21以上では必ず単数形folder
- enchantment/painting/jukeboxのinline推測よりregistry entryを使う
- 1.21.2のingredient/attribute prefix変更を先取りしない
