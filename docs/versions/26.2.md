# Java Edition 26.2

data pack format 107.1。entity predicateのcomponent-map化と厳格化が最大の移行点です。

## metadata

```json
{
  "pack": {
    "description": "26.2 data pack",
    "min_format": [107, 1],
    "max_format": [107, 1]
  }
}
```

## コマンド

- `/unpublish`
- advancement grant/revokeのresult/reportを変更件数・player数へ修正
- team/waypoint colorはlowercase snake_caseのみ
- `execute on owner` がVexのEvoker ownerを考慮

## entity predicate

旧optional field objectからcomponent mapへ。

```json
{
  "minecraft:entity_type": "minecraft:player"
}
```

- 全keyはnamespaced ID。namespace省略時は `minecraft`
- 旧 `type` → `minecraft:entity_type`
- type-specific sub-predicateをtop-level namespaced keyへ
- `type_specific/slime→type_specific/cube_mob`
- unknown keyを無視せず拒否
- `minecraft:entity_tags` sub-predicate

## JSON/NBT/registry

- `sulfur_cube_archetype` と `sulfur_cube_content` component
- `bounciness`, `name_tag_distance`, `below_name_distance` 等のattribute
- Living Entity `HurtByTimestamp` を削除し `ticks_since_last_hurt_by_mob`
- bed block entityを削除
- worldgen feature/surface rule/density functionを追加・rename
- `dimension_type.infiniburn` 等のfieldがID/list/tagを受付

## 互換性

26.1.x predicate JSONはunknown fieldの黙認に依存できません。全 entity predicateを再生成してreloadします。

## JSONパラメータ差分

- **item**: `minecraft:sulfur_cube_content` componentと`sulfur_cube_archetype/` registryを追加。その他の既存item component schemaは26.1.2を継承
- **dimension/worldgen**: configured feature、surface rule、density functionのtypeを追加・rename。`dimension_type.infiniburn`等は単一ID、ID list、tagを受け付ける
- **enchantment**: definition/effect/provider type集合は26.1.2を継承。`requirements`内の`entity_properties.predicate`は26.2 component-map形式へ変更し、旧`type`や旧type-specific wrapperを削除
- **variant**: 13種のvariant registryと26.1 sound wrapperを継承。variant root schemaの固有追加・削除なし
- **predicate**: entity predicateをnamespaced component mapへ全面変更し、旧`type`を`minecraft:entity_type`へ、旧type-specific wrapperをtop-level keyへ移行。未知keyは拒否
- **advancement**: root/trigger集合は26.1.2を継承するが、criteriaのplayer/entity/location等に埋め込むentity predicateを26.2 component-map形へ再生成
- **loot_table**: root/pool/entry/function集合は26.1.2を継承するが、`entity_properties`等のconditionに埋め込むentity predicateを26.2形へ更新
- **recipe**: 26.1.2のinline ingredient、統一result、special serializer schemaを継承。固有の追加・変更・削除なし
- **item_modifier**: function集合は26.1.2を継承するが、各functionの`conditions`やnested predicate内のentity predicateを26.2形へ更新
- **互換性**: entity predicateは未知keyを拒否するため、enchantment condition、loot、advancement、item component内を含む全埋め込みpredicateを再生成する

## AI 生成規則

- entity predicateで旧 `type` fieldを出力しない
- 未知keyを将来互換placeholderとして残さない
- team/waypoint色は `dark_purple` のようなlowercase snake_case
- 107.1の新registry/attributeは26.1 overlayへ漏らさない
