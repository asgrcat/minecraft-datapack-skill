# Java Edition 1.14.3

1.14.2 を継承し、pack format は4です。

## 差分

- gamerule `disableRaids` を追加
- vanilla advancement “How Did We Get Here?” から Saturation 要件を削除
- 壊れた recipe JSON が pack を無言で load 不能にする問題、reload 中の tag 参照 crash 等を修正

## JSONパラメータ差分

- item: `inherits: 1.14.2`。item、recipe、lootのparameterにこの版固有の変更はなく、不正recipeの診断修正をschema緩和として扱わない
- dimension/worldgen: 1.14.2を継承し、custom registryは未対応
- enchantment: 1.14.2の固定registryとitem NBT形式を継承
- variant: 1.14.2を継承し、data-driven variant registryはない
- predicate: 1.14.2を継承し、独立resourceは未対応。この版固有の追加・変更・削除はない
- advancement: 1.14.2のadvancement schemaを継承し、この版固有の追加・変更・削除はない
- loot_table: 1.14.2のloot table schemaを継承し、この版固有の追加・変更・削除はない
- recipe: 1.14.2のrecipe schemaを継承し、不正recipeの診断修正をschema変更とは扱わない
- item_modifier: 1.14.2を継承し、独立resourceは未対応。この版固有の追加・変更・削除はない

## AI 生成規則

`disableRaids` を使う最小バージョンは1.14.3とし、不正 JSON の診断改善を schema 緩和と解釈しません。
