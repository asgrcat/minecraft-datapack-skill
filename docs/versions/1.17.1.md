# Java Edition 1.17.1

1.17 のデータパック/command/JSON 仕様を継承する hotfix です。

## JSONパラメータ差分

- item: `inherits: 1.17`。`/item`、item modifier、旧`tag` NBT、recipe/loot/predicate parameterにこの版固有の変更はない
- dimension/worldgen: 1.17を継承し、この版固有のworldgen schema変更はない
- enchantment: 1.17の固定registryとitem NBT形式を継承
- variant: 1.17を継承し、data-driven variant registryはない
- predicate: 1.17のpredicate schemaを継承し、この版固有の追加・変更・削除はない
- advancement: 1.17のadvancement schemaを継承し、この版固有の追加・変更・削除はない
- loot_table: 1.17のloot table schemaを継承し、この版固有の追加・変更・削除はない
- recipe: 1.17のrecipe schemaを継承し、この版固有の追加・変更・削除はない
- item_modifier: 1.17のitem modifier schemaを継承し、この版固有の追加・変更・削除はない

## AI 生成規則

format 7と `/item` 構文を使い、1.18の loot/worldgen変更を入れません。
