# Java Edition 1.15

data pack format 5。再利用可能な predicate と command storage が中心です。

## 新機能

- `data/<namespace>/predicates/<id>.json`。loot condition を独立 resource 化
- `execute if predicate <id>`、selector `predicate=<id>`
- command storage: `/data ... storage <id>` と `/execute store ... storage`。全 dimension 共有で永続
- `/schedule ... [append|replace]` と `/schedule clear <id>`
- `/spectate`、text click event `copy_to_clipboard`
- loot condition `reference`, `time_check`、loot function `copy_state`

## JSON

- predicate はこのバージョンでは基本 top-level object
- entity predicate に player (`level`, `gamemode`, `stats`, `recipes`, `advancements`)、team
- location predicate に block/fluid/light
- raw JSON text NBT component の source に `storage`

## 互換性

形式4から5へ変更。1.14.4向け JSON を単に形式5に上げず、predicate 抽出と loot context を検査します。

## JSONパラメータ差分

- item: 旧`tag` NBTを継続。独立predicate resourceを追加し、item/entity/location条件をloot conditionと再利用できるようにした
- dimension/worldgen: custom dimension/worldgen registryは未対応。location predicateのblock/fluid/lightはworldgen定義ではない
- enchantment: 固定registryを継承し、新しいenchantment definitionはJSONで追加できない
- variant: data-driven variant registryは未対応
- predicate: `predicates/<id>.json`を追加。単一loot condition objectを`execute if predicate`、selectorの`predicate=`、`reference` conditionから再利用可能
- advancement: item predicateの通常enchantmentと`stored_enchantments`を分離し、entityのplayer/team、locationのblock/fluid/light等を追加
- loot_table: `reference`、`time_check` conditionと`copy_state` functionを追加し、独立predicate resourceと同じloot condition形式を共有
- recipe: 1.14.4のrecipe type、ingredient、result schemaを継承し、この版固有の追加・変更・削除はない
- item_modifier: 独立item modifier resourceは未対応。loot functionの再利用resource化は1.17で導入

## AI 生成規則

- predicate を使う最小バージョンは1.15
- top-level predicate array は1.16のため、1.15では単一 object/明示的な合成 condition を使う
- item modifier は1.17まで使わない
