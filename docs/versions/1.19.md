# Java Edition 1.19

data pack format 10。`/locate` 統合、`/place`、metadata filter、chat type が中心です。

## コマンド

- `/place feature|jigsaw|structure|template ...` が `/placefeature` を置換
- `/locate structure|biome|poi`
- `/locatebiome` を削除し `/locate biome` へ

## JSON

- `pack.mcmeta` top-level `filter.block[]`。下位優先度 pack の namespace/path を正規表現で隠す
- `worldgen/world_preset`, `worldgen/flat_level_generator_preset`
- `chat_type` registry
- item modifier `set_instrument`
- location predicate `feature` → `structure`
- entity predicate の variant fields を `type_specific` へ統合
- custom dimension の `seed` を削除
- dimension type に monster spawn light fields

## rename

game event を多数整理。例: `drinking_finish→drink`, `entity_killed→entity_die`, `entity_damaged→entity_damage`, `elytra_free_fall→elytra_glide`, `mob_interact→entity_interact`。

## JSONパラメータ差分

- **item**: `set_instrument` item modifier を追加。アイテムスタック本体は 1.18.2 の NBT 形式を継承する。
- **dimension/worldgen**: `configured_structure_feature`を`structure`へ移行。dimension JSONのルート`seed`を削除してworld seedを共用し、`worldgen/world_preset`と`worldgen/flat_level_generator_preset`を追加。dimension typeへ`monster_spawn_light_level`（整数またはint provider）と`monster_spawn_block_light_limit`（整数）を追加したため、1.18.2向けcustom worldgen/dimensionは移植時に更新する。
- **enchantment**: enchantment は固定レジストリのままで、単独のデータ駆動 JSON はない。1.18.2 の挙動を継承する。
- **variant**: エンティティ固有の variant 条件を entity predicate の `type_specific` 以下へ集約。単独の variant レジストリ JSON はまだない。
- **predicate**: location predicate の `feature` を `structure` へ rename。entity predicate の相互排他的な `player`、`fishing_hook`、`lightning_bolt`、`catType` を discriminator `type` を持つ `type_specific` へ置換し、frog と slime の sub-predicate も追加したため、1.18.2 の旧fieldは書き換える。
- **advancement**: `kill_mob_near_sculk_catalyst`、`thrown_item_picked_up_by_player`、`allay_drop_item_on_block`、`avoid_vibration` trigger を追加。`location`、`slept_in_bed`、`hero_of_the_village`、`voluntary_exile` trigger の重複 `location` field は削除され、`player.location` へ統合されたため旧conditionは非互換。
- **loot_table**: loot function `set_instrument` を追加し、`options` にinstrument tagを指定して候補から選択する。loot tableのroot、pool、entryは1.18.2を継承するが、このfunctionを含む定義は1.18.2以前では利用できない。
- **recipe**: recipe JSONのtype別fieldは1.18.2を継承し、この版固有の追加・変更・削除はない。gameplay上のminecart recipe変更とcustom recipe schema変更を混同しない。
- **item_modifier**: loot functionと共通の `set_instrument` を追加。`options` はinstrument ID単体ではなくinstrument tag参照であり、このmodifierを1.18.2以前へ持ち込めない。

## AI 生成規則

- 旧 `/placefeature` と `/locatebiome` を出力しない
- filter は自分自身には作用しない。両 regex field を明示する
- 1.19.1/1.19.3も同じ format 10だが別 profileとして扱う
