# Java Edition 1.16.3

piglin 関連の2件を修正した hotfix です。1.16.2のデータパック仕様を継承します。

## JSONパラメータ差分

- item: `inherits: 1.16.2`。item、recipe、loot、predicate parameterにこの版固有の変更はない
- dimension/worldgen: 1.16.2のformat 6とexperimental worldgen registryを継承し、この版固有のschema変更はない
- enchantment: 1.16.2の固定registryとitem NBT形式を継承
- variant: 1.16.2を継承し、data-driven variant registryはない
- predicate: 1.16.2のpredicate schemaを継承し、この版固有の追加・変更・削除はない
- advancement: 1.16.2のadvancement schemaを継承し、この版固有の追加・変更・削除はない
- loot_table: 1.16.2のloot table schemaを継承し、この版固有の追加・変更・削除はない
- recipe: 1.16.2のrecipe schemaを継承し、この版固有の追加・変更・削除はない
- item_modifier: 1.16.2を継承し、独立resourceは未対応。この版固有の追加・変更・削除はない

## AI 生成規則

format 6、1.16.2 worldgen schema、同じ command graph を基底にします。
