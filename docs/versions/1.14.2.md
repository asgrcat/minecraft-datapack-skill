# Java Edition 1.14.2

1.14.1 の command/JSON schema を継承します。

## 差分

- 新しいデータパック schema/command はありません
- vanilla `#minecraft:slabs` への `cut_sandstone_slab` 欠落等を修正
- advancement/beacon 等の不具合を修正

## JSONパラメータ差分

- item: `inherits: 1.14.1`。item/recipe/loot schemaは継承し、vanilla tag内容の修正だけを対象版生成物で確認する
- dimension/worldgen: 1.14.1を継承し、custom registryは未対応
- enchantment: 1.14.1の固定registryとitem NBT形式を継承
- variant: 1.14.1を継承し、data-driven variant registryはない
- predicate: 1.14.1を継承し、独立resourceは未対応。この版固有の追加・変更・削除はない
- advancement: 1.14.1のadvancement schemaを継承し、この版固有の追加・変更・削除はない
- loot_table: 1.14.1のloot table schemaを継承し、この版固有の追加・変更・削除はない
- recipe: 1.14.1のrecipe schemaを継承し、この版固有の追加・変更・削除はない
- item_modifier: 1.14.1を継承し、独立resourceは未対応。この版固有の追加・変更・削除はない

## AI 生成規則

custom tag で vanilla tag 内容を前提にする場合、1.14.2 の生成済み vanilla tag を使います。
