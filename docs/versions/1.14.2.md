# Java Edition 1.14.2

1.14.1 の command/JSON schema を継承します。

## 差分

- 新しいデータパック schema/command はありません
- vanilla `#minecraft:slabs` への `cut_sandstone_slab` 欠落等を修正
- advancement/beacon 等の不具合を修正

## AI 生成規則

custom tag で vanilla tag 内容を前提にする場合、1.14.2 の生成済み vanilla tag を使います。
