# Java Edition 1.19.1

pack format 10のまま chat component と `chat_type` が変わります。

## 変更

- raw JSON text の `clickEvent.run_command` 値は `/` 始まりが必須
- command から signed player chat を生成できない。system message は `/tellraw` 等を使う
- `chat_type` の system/game_info を削除し、chat/narration decoration 中心へ
- msg/team_msg を incoming/outgoing に分割
- `team_name` → `target`

## 互換性

1.19向け `chat_type` は形式警告なしで意味が変わります。chat resource を使う pack は必ず1.19.1用へ分離します。

## AI 生成規則

format番号だけで1.19と同一 schemaにせず、chat_type と click commandを上書きします。
