# Java Edition 1.14

pack format は4のままですが、loot table と NBT 操作は大幅に変わります。同形式を完全互換と扱ってはいけません。

## コマンド

- `/loot <target> <source>`: source は `fish|loot|kill|mine`、target は `spawn|replace entity|replace block|give|insert`
- `/schedule function|tag <time>`。`t`, `s`, `d` 単位
- `/teammsg` (`/tm`)
- `/data modify <target> <path> set|insert|prepend|append|merge from|value`
- `/execute if|unless data`
- NBT path に複数値、`[]`, `[-1]`, `[{...}]`, `{...}` の match

## JSON

- block drop を `loot_tables/blocks/<block>.json` でデータ駆動化
- loot table に context `type`、composite entry、table/pool function、多数の condition/function
- `entity_properties` は advancement と同系の predicate object を取る
- `tags/entity_types` と selector `type=#tag`
- recipe に blasting、smoking、campfire cooking、stonecutting
- raw JSON text に NBT component (`nbt` + `entity|block` + `interpret`)

## 互換性と移行

1.13 loot table の condition/function は1.14の context validation で再検証します。block drop override は新機能です。1.15 の独立 predicate file や storage はまだ使えません。

## AI 生成規則

- `pack_format: 4` でも `target_version: 1.14` を別判定する
- loot table の `type` と利用可能 context parameter を明示する
- `/schedule` の後世の `append|replace`/`clear` を1.14へ逆輸入しない
