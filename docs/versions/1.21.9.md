# Java Edition 1.21.9

data pack format 88.0。pack versionへminorを導入し、`pack.mcmeta` の互換範囲schemaを変更します。

## `pack.mcmeta`

```json
{
  "pack": {
    "description": "1.21.9 data pack",
    "min_format": [88, 0],
    "max_format": [88, 0]
  }
}
```

- `min_format`, `max_format` 必須
- data format 82未満を範囲に含まないpackでは `supported_formats` を禁止
- 旧範囲を含まないなら `pack_format` は省略可能
- 同一major内のminor増加は後方互換。新minor機能依存なら `min_format` のminorを上げる

## コマンド/データ

- `/fetchprofile name|id`
- `spawnpoint`, `setworldspawn` のangleをrotationへ。world spawn/command default dimensionの意味変更
- `minecraft:mannequin` technical entity
- world borderをdimension別化
- text `object` component（atlas sprite/player）
- profile component/block entityの自動resolve/書換を廃止しstatic/dynamic semanticsへ
- interaction loot context、harvest/carve/brush等loot table
- worldgen density function追加と noise settings field rename
- `minecraft:chain→minecraft:iron_chain`

## JSONパラメータ差分

- **item**: textにatlas sprite/playerを表す`object` componentを追加。profile component/block entityの自動resolve・書換を廃止してstatic/dynamic semanticsへ分離し、object textのatlas sprite参照を1.21.8以前から分ける
- **dimension/worldgen**: world borderをdimension別化。noise settingsの`initial_density_without_jaggedness`を`preliminary_surface_level`へ置換し、density function typeを追加
- **enchantment**: `minecraft:explode` entity effectへ重み付き`block_particles` entryを追加。entryは`weight`、`particle`と任意の`scaling`、`speed`を持つ。その他のroot/provider schemaは継承
- **variant**: painting、mob visual、sound variantのfield構造に固有変更なし
- **predicate**: `entity_scores.entity`と`entity_properties.entity`へinteraction contextの`target_entity`、`interacting_entity`を追加。通常contextに両entityが常在するとは扱わない
- **advancement**: root、criteria、trigger、reward schemaは1.21.8を継承。interaction loot contextの追加を新advancement triggerとして推測しない
- **loot_table**: `minecraft:entity_interact`と`minecraft:block_interact` context type、interaction/harvest/brush/carve等のvanilla tableを追加。対応function/predicateのentity source/target enumも拡張
- **recipe**: ingredient、result、serializer集合は1.21.8を継承。固有の追加・変更・削除なし
- **item_modifier**: function list自体は継承。`fill_player_head`、`set_lore`、`copy_custom_data`、`copy_name`、`copy_components`等のcontext source/target enumを拡張するが、`/item modify`がinteraction contextを供給するとは限らない
- **互換性**: `pack.mcmeta`を`min_format`/`max_format`へ移行。旧noise field、旧profile semantics、新minor機能を使うpackは1.21.8以前と分離

## AI 生成規則

- `pack_format: 88.0` のようなJSON numberだけを旧最小形へ入れない。新range schemaを生成する
- item sprite/atlas、profile、world borderは1.21.8以前と分ける
- min/maxのminor意味を [`compatibility.md`](../compatibility.md) の規則どおりに扱う
