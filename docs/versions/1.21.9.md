# Java Edition 1.21.9

data pack format 88.0。pack versionへminorを導入し、`pack.mcmeta` の互換範囲schemaを変更します。

## `pack.mcmeta`

```json
{
  "pack": {
    "description": "1.21.9 data pack",
    "min_format": [88, 0],
    "max_format": [88, 0]
  }
}
```

- `min_format`, `max_format` 必須
- data format 82未満を範囲に含まないpackでは `supported_formats` を禁止
- 旧範囲を含まないなら `pack_format` は省略可能
- 同一major内のminor増加は後方互換。新minor機能依存なら `min_format` のminorを上げる

## コマンド/データ

- `/fetchprofile name|id`
- `spawnpoint`, `setworldspawn` のangleをrotationへ。world spawn/command default dimensionの意味変更
- `minecraft:mannequin` technical entity
- world borderをdimension別化
- text `object` component（atlas sprite/player）
- profile component/block entityの自動resolve/書換を廃止しstatic/dynamic semanticsへ
- interaction loot context、harvest/carve/brush等loot table
- worldgen density function追加と noise settings field rename
- `minecraft:chain→minecraft:iron_chain`

## AI 生成規則

- `pack_format: 88.0` のようなJSON numberだけを旧最小形へ入れない。新range schemaを生成する
- item sprite/atlas、profile、world borderは1.21.8以前と分ける
- min/maxのminor意味を [`compatibility.md`](../compatibility.md) の規則どおりに扱う
