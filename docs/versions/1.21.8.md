# Java Edition 1.21.8

graphics corruption/crashの hotfix です。データパック仕様は1.21.7を継承します。

## JSONパラメータ差分

- **item**: 1.21.7のitem componentとjukebox参照を継承。固有の追加・変更・削除なし
- **dimension/worldgen**: 1.21.7のdimension/worldgen codecを継承。固有変更なし
- **enchantment**: 1.21.7のdefinition/effect/provider schemaを継承。固有変更なし
- **variant**: 1.21.7のpainting/mob/sound variant schemaとentryを継承。固有変更なし
- **predicate**: 直接親1.21.7のstrict predicate schemaを継承。固有の追加・変更・削除なし
- **advancement**: 直接親1.21.7のstrict root、criteria、trigger、reward schemaを継承。固有の追加・変更・削除なし
- **loot_table**: 直接親1.21.7のstrict root、pool、entry、condition、function schemaを継承。固有の追加・変更・削除なし
- **recipe**: 直接親1.21.7のstrict ingredient/result/serializer schemaを継承。固有の追加・変更・削除なし
