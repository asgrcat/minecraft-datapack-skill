# Java Edition 1.20.4

1.20.3 のデータパック/command/JSON 仕様を継承する hotfix です。decorated pot 等の不具合を修正します。

## JSONパラメータ差分

- **item**: 1.20.3 の item JSON／NBT を継承する hotfix で、この版固有の追加・変更・削除はない。
- **dimension/worldgen**: 1.20.3 の定義を継承する hotfix で、この版固有の差分はない。
- **enchantment**: 固定レジストリのまま 1.20.3 を継承し、この版固有の差分はない。
- **variant**: 1.20.3 の entity predicate を継承し、この版固有の差分はない。
- **predicate**: 1.20.3 のpredicate形式を直接継承するhotfixで、このカテゴリ固有の追加・変更・削除はない。
- **advancement**: 1.20.3 のadvancement root、trigger、conditionを直接継承するhotfixで、このカテゴリ固有の追加・変更・削除はない。
- **loot_table**: 1.20.3 のloot table、condition、functionを直接継承するhotfixで、このカテゴリ固有の追加・変更・削除はない。
- **recipe**: 1.20.3 のrecipe形式を直接継承するhotfixで、このカテゴリ固有の追加・変更・削除はない。
- **item_modifier**: 1.20.3 のitem modifier形式を直接継承するhotfixで、このカテゴリ固有の追加・変更・削除はない。

## AI 生成規則

format 26のfunction result/text component仕様を使い、1.20.5のitem component構文は使いません。
