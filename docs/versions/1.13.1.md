# Java Edition 1.13.1

1.13 を継承します。pack format は4のままです。

## コマンドと挙動

- `/forceload add|remove|query|all` を正式に追加
- scoreboard `%=` を Java の truncating remainder から `floorMod` へ変更。負数の結果が変わる（例: `-1 %= 7` は `6`）
- function parse error の行番号を0始まりから1始まりへ修正
- `minecraft:underwater_bonemeals` block tag を追加
- container `CustomName` JSON、advancement criterion の colon、補完 namespace、selector parser 等を修正

## 互換性

1.13向け pack は原則同じ配置で読み込めますが、負数 modulo と `/forceload` に依存する処理はバージョンを区別します。

## JSONパラメータ差分

- item: `inherits: 1.13`。item stack、recipe、lootのparameterにこの版固有の変更はない
- dimension/worldgen: 1.13を継承し、custom registryは未対応
- enchantment: 1.13の固定registryとitem NBT形式を継承
- variant: 1.13を継承し、data-driven variant registryはない
- predicate: 1.13を継承し、独立resourceは未対応。この版固有の追加・変更・削除はない
- advancement: 1.13のadvancement schemaを継承し、この版固有の追加・変更・削除はない
- loot_table: 1.13のloot table schemaを継承し、この版固有の追加・変更・削除はない
- recipe: 1.13のrecipe schemaを継承し、この版固有の追加・変更・削除はない
- item_modifier: 1.13を継承し、独立resourceは未対応。この版固有の追加・変更・削除はない

## AI 生成規則

- `/forceload` を使う生成物の最小バージョンは1.13.1とする
- 1.13との共通実装で負数 `%=` を使う場合は結果を実機確認する
