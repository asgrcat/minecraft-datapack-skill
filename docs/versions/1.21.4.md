# Java Edition 1.21.4

data pack format 61。custom model data、particle、furnace/TNT NBTが変わります。

## 変更

- `/attribute <target> <attribute> base reset`
- `trail` particleに必須 `duration`
- `entity_data`/`block_entity_data` componentは対象 `id` が実体typeと一致する場合だけ適用
- `custom_model_data` を数値から `{floats,flags,strings,colors}` へ
- `equippable.model→asset_id`
- furnace NBT `CookTime/CookTimeTotal/BurnTime` → `cooking_time_spent/cooking_total_time/lit_time_remaining` と `lit_total_time`
- TNT minecart `TNTFuse→fuse`

## JSONパラメータ差分

- **item**: `custom_model_data`を単一数値から`floats`、`flags`、`strings`、`colors`のobjectへ変更。`equippable.model`を`asset_id`へrenameし、`entity_data`/`block_entity_data`は対象実体と一致する`id`を要求
- **dimension/worldgen**: 1.21.3のdimension/worldgen schemaを継承。particle定義では`trail.duration`が必須になり、worldgenから同particleを参照する場合も更新が必要
- **enchantment**: definition、provider、effect component registryに固有変更なし。effect内particleが`trail`を使う場合は新しい必須fieldに従う
- **variant**: painting/wolf variantのroot schemaに固有変更なし
- **predicate**: root/condition typeは1.21.3を継承するが、exact component検査で数値の旧`custom_model_data`を使わず`floats`、`flags`、`strings`、`colors`のobjectへ更新
- **advancement**: root/trigger schemaに固有変更なし。iconやcriteria内item predicateで変更対象componentを使う場合は1.21.4のcomponent形へ更新
- **loot_table**: root/pool/entry schemaに固有変更なし。conditionやfunctionで`custom_model_data`等を比較・生成する場合は1.21.4のcomponent形へ更新
- **recipe**: ingredient serializerに固有変更なし。component付きresultの`custom_model_data`、`equippable`、entity/block dataは1.21.4形へ更新
- **item_modifier**: `minecraft:set_custom_model_data`を`floats`、`flags`、`strings`、`colors`ごとのlist operationへ拡張。旧単一数値fieldは移行が必要
- **互換性**: 数値`custom_model_data`、旧`equippable.model`、種類不一致を許したentity/block data componentは共有不可

## AI 生成規則

- 旧数値 `custom_model_data` を出力しない
- block/entity data componentのidを明示し、種類不一致を利用しない
- 1.21.5のSNBT text/equipment NBTを先取りしない
