# Java Edition 1.21.5

data pack format 71。text component、SNBT、entity equipment/variant、item tooltipを大改編します。

## コマンド

- `/test` と data-driven GameTest (`test_instance`, `test_environment`, structure)
- `/setblock`, `/fill`, `/clone`, `/place template` に `strict`
- block placementでNBT未指定なら既存block entity dataを保持。明示消去は `{}`
- target selector `@n` はこの版でも利用可能（1.21導入）

## text/SNBT

- `tellraw`, `title` 等のtext componentをJSON文字列で包まずSNBT objectとして直接記述する場面へ
- `hoverEvent/clickEvent→hover_event/click_event`、action別fieldをinline化
- SNBTにheterogeneous list、trailing comma、数値表現、`bool()`, `uuid()` 等

## component/NBT/JSON

- tooltip制御を `minecraft:tooltip_display` に集約。旧 `show_in_tooltip`, `hide_tooltip` 等を移行
- entity variantをentity componentへ
- equipmentを共通 `equipment` fieldへ。旧 `ArmorItems`, `HandItems`, `SaddleItem`, `Saddle` 等を削除
- entity/block predicateに `components`, `predicates`
- data-driven pig/cow/chicken/cat/frog variants、wolf sound variant
- potion entityを splash/lingeringへ分割
- recipe result component patchとsmithing ingredientを厳格化

## AI 生成規則

- 1.21.4以前のJSON文字列text/NBT wrapperを出力しない
- tooltipはcomponent単位の旧booleanでなく `tooltip_display`
- entity equipment/variantは新component/fieldを使う
- `/data`のheterogeneous list対応を古いoverlayへ漏らさない
