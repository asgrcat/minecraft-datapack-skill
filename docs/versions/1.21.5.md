# Java Edition 1.21.5

data pack format 71。text component、SNBT、entity equipment/variant、item tooltipを大改編します。

## コマンド

- `/test` と data-driven GameTest (`test_instance`, `test_environment`, structure)
- `/setblock`, `/fill`, `/clone`, `/place template` に `strict`
- block placementでNBT未指定なら既存block entity dataを保持。明示消去は `{}`
- target selector `@n` はこのバージョンでも利用可能（1.21導入）

## text/SNBT

- `tellraw`, `title` 等のtext componentをJSON文字列で包まずSNBT objectとして直接記述する場面へ
- `hoverEvent/clickEvent→hover_event/click_event`、action別fieldをinline化
- SNBTにheterogeneous list、trailing comma、数値表現、`bool()`, `uuid()` 等

## component/NBT/JSON

- tooltip制御を `minecraft:tooltip_display` に集約。旧 `show_in_tooltip`, `hide_tooltip` 等を移行
- entity variantをentity componentへ
- equipmentを共通 `equipment` fieldへ。旧 `ArmorItems`, `HandItems`, `SaddleItem`, `Saddle` 等を削除
- entity/block predicateに `components`, `predicates`
- data-driven pig/cow/chicken/cat/frog variants、wolf sound variant
- potion entityを splash/lingeringへ分割
- `crafting_transmute.result`へcomponent patch/countを追加し、`smithing_transform.base`と`smithing_trim`のbase/template/additionを必須化

## JSONパラメータ差分

- **item**: tooltip制御を`minecraft:tooltip_display`へ集約し、各componentの`show_in_tooltip`とitem全体の`hide_tooltip`を移行。entity equipment/variant用componentを追加し、`crafting_transmute.result`へcomponent patchとcountを追加。`smithing_transform.base`と`smithing_trim`のbase/template/additionを必須化
- **dimension/worldgen**: 1.21.4のdimension/worldgen codecを継承。`test_environment`、`test_instance`、structureによるdata-driven GameTestは追加されるが、dimension definitionの置換ではない
- **enchantment**: root fieldsとeffect type集合は1.21.4を継承。`requirements`内のentity/block predicateは新しい`components`、`predicates` fieldを利用でき、text component表現の変更もdescriptionへ適用
- **variant**: pig/cow/chicken/cat/frog variantとwolf sound variantをpack定義化。自然spawn規則を`spawn_conditions[{condition?,priority}]`へ統一し、wolfは`assets.{wild,tame,angry}`へ再編
- **predicate**: entity/block predicateへexact値用`components`とsub-predicate用`predicates`を追加。item predicateもtooltip/component簡略形と新component codecへ追従
- **advancement**: `display.background`から`textures/` prefixと`.png` suffixを削除。criteria内のentity/block/item predicateとdisplay text/iconは1.21.5のpredicate・text・component形へ更新
- **loot_table**: root/pool/entryの構造は1.21.4を継承。conditionのentity/block/item predicate、textを扱うfunction、component functionは1.21.5形へ更新
- **recipe**: `crafting_transmute.result`へ任意のcomponent patchとcountを追加。`smithing_transform`では`base`、`smithing_trim`では`base`、`template`、`addition`を必須化。trimはpattern参照を含む対象バージョンのvanilla形を使う
- **item_modifier**: root object/listは継承するが、`set_name`/`set_lore`等のtextと`set_components`等の値を1.21.5形へ更新し、旧tooltip booleanを出力しない
- **互換性**: 旧wolf texture fields、旧variant/equipment NBT、componentごとのtooltip booleanは手動移行が必要

## AI 生成規則

- 1.21.4以前のJSON文字列text/NBT wrapperを出力しない
- tooltipはcomponent単位の旧booleanでなく `tooltip_display`
- entity equipment/variantは新component/fieldを使う
- `/data`のheterogeneous list対応を古いoverlayへ漏らさない
