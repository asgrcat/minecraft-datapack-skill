# Java Edition 1.13

データパックの正式な起点です。1.12 の function/recipe/advancement を含む command system は Flattening と Brigadier によりほぼ全面移行が必要です。

## pack と配置

```json
{
  "pack": {
    "pack_format": 4,
    "description": "1.13 data pack"
  }
}
```

`data/<namespace>/functions`, `loot_tables`, `advancements`, `recipes`, `structures`, `tags/{blocks,items,functions}` を使います。function は1行1 command、先頭 `/` なし、`#` 行コメントです。`#minecraft:load` と `#minecraft:tick` が入口です。

## 新機能

- `/datapack`, `/function`, `/reload` で pack/function を管理
- Brigadier command parser、`^left ^up ^forward`、range、selector `nbt=`
- `/execute` を `as/at/positioned/align/facing/rotated/in/anchored`, `if/unless`, `store`, `run` の連結型へ全面再設計
- `/bossbar`, `/data`, `/tag`, `/team`
- recipe、advancement、loot table、tag、structure を namespace 配下へ統合

## 削除・移行

- 数値 block/item ID と metadata を削除。固有 namespaced ID と block state/NBT へ
- `/blockdata`, `/entitydata` → `/data`
- `/testfor*`, 旧 `/execute` 条件 → 新 `/execute if|unless`
- `scoreboard teams` → `/team`、`scoreboard players tag` → `/tag`
- `CustomName` 等の文字列は raw JSON text component 化
- item `ench` → `Enchantments` と文字列 enchantment ID
- 1.12 structure は1.12で読み込み、1.13で再保存してから配布する

## JSONパラメータ差分

- item: データパック正式化の基準版。数値IDとmetadataを廃止し、namespaced item IDと旧`tag` NBTを使う。`ench`は`Enchantments`、enchantment IDは文字列resource locationへ移行
- dimension/worldgen: custom `dimension`、`dimension_type`、`worldgen/*` registryはまだデータパックから定義できない
- enchantment: built-in enchantmentのIDとlevelをitem NBTへ保存できるが、新しいenchantment definitionはJSONで追加できない
- variant: entity固有NBT等で既存variantを選ぶ時代であり、data-driven variant registryはない
- predicate: 独立predicate resourceはまだなく、advancement triggerやloot condition内のitem/entity/location等のpredicateを使用する
- advancement: `advancements/<id>.json`をデータパック正式化の基準形とし、`criteria`、`requirements`、`rewards`、`display`で定義する
- loot_table: `loot_tables/<id>.json`を基準形とし、pool、entry、condition、functionを対象context内で評価する
- recipe: `recipes/<id>.json`を基準形とし、crafting shaped/shapeless、smelting等の既存recipe typeをnamespaced IDで定義する
- item_modifier: 独立item modifier resourceは未対応。loot functionを再利用する`item_modifiers/`は1.17まで利用不可

## AI 生成規則

- 1.14 以降の `/data modify`, `/loot`, `/schedule`、predicate、storage を使わない
- item component (`[...]`) や単数形 folder を使わない
- 旧 command を機械的に部分置換せず command tree 全体を1.13で生成し直す
