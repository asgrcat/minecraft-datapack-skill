# Java Edition 1.20.3

data pack format 26。開発中の19〜26の変更を累積し、function result と text component validationを変更します。

## コマンド

- `/tick query|rate|freeze|step|unfreeze|sprint`。高permissionで通常packからの利用を前提にしない
- `execute if|unless function` を再導入
- `return run <command>` を再導入、`return fail` を追加
- function は `return` がない限り resultを持たない。`execute store ... run function` の旧「各child commandをstore」挙動を削除
- `maxCommandChainLength` の数え方を operation基準へ。`maxCommandForkCount`
- scoreboard entry display name と number format

## JSON/NBT/ID

- text componentを厳格化。`null`/`[]`を無効とし、不正color/click/hover等を拒否
- optional `type`、NBT component `source`
- jigsaw `pool_aliases`、max size 20
- TNT `Fuse→fuse`、trident `Trident→item` 等
- `minecraft:grass` → `minecraft:short_grass`

## JSONパラメータ差分

- **item**: item 名・lore などに使う text component の JSON 検証が厳格化され、NBT キー名の変更も含むため 1.20.2 向けデータを再検証する。アイテムスタック本体は引き続き NBT 形式で、item component 形式への移行前である。
- **dimension/worldgen**: jigsaw structure に `pool_aliases` を追加し、最大サイズを 20 に拡張。resource location の `grass` は `short_grass` に改名されたため、worldgen 内の参照も更新する。
- **enchantment**: 固定レジストリのまま 1.20.2 を継承し、この版固有の JSON 差分はない。
- **variant**: `type_specific` を含む entity predicate は 1.20.2 を継承し、この版固有の variant レジストリ追加はない。
- **predicate**: predicate codec自体は1.20.2を継承し、このカテゴリ固有のcondition追加・削除はない。ただしblock／item ID `minecraft:grass` は `minecraft:short_grass` へrenameされたため、該当IDを使うpredicateは更新する。
- **advancement**: rootとtriggerは1.20.2を継承する。`display.title`／`description` 等のtext componentでは `null` と空配列が拒否され、不正なstyleもsilent ignoreされなくなったため、旧表示componentを再検証する。
- **loot_table**: root、entry、condition、functionは1.20.2を継承する。`set_name`／`set_lore` 等のtext componentは1.20.3の厳格なcomponent parsingに従い、`minecraft:grass` 参照は `minecraft:short_grass` へ更新する。
- **recipe**: type別fieldは1.20.2を継承し、このカテゴリ固有のschema追加・削除はない。ingredient／resultの `minecraft:grass` は `minecraft:short_grass` へrenameされ、旧IDとは互換でない。
- **item_modifier**: function集合は1.20.2を継承する。`set_name`／`set_lore` のtext componentは `null`／空配列や不正styleを受理しないため再検証し、grass ID参照もrenameする。

## AI 生成規則

- functionの成否/resultを1.20.2以前と同じにしない
- `return run` のfork/失敗を対象バージョンのcommand resultでtestする
- 1.21 experimental resourceをstable baselineへ含めない
