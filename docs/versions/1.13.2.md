# Java Edition 1.13.2

1.13.1 のデータパック配置、JSON schema、`.mcfunction` 構文をそのまま継承します。pack format は4です。

## 差分

- authoring schema と command の追加はありません
- performance、world upgrade、安全性を修正
- spawn egg を介した任意 command 実行の不具合修正により、バグ依存 pack の挙動は変わり得ます

## JSONパラメータ差分

- item: `inherits: 1.13.1`。item系JSON/NBT parameterにこの版固有の変更はない
- dimension/worldgen: 1.13.1を継承し、custom registryは未対応
- enchantment: 1.13.1の固定registryとitem NBT形式を継承
- variant: 1.13.1を継承し、data-driven variant registryはない
- predicate: 1.13.1を継承し、独立resourceは未対応。この版固有の追加・変更・削除はない
- advancement: 1.13.1のadvancement schemaを継承し、この版固有の追加・変更・削除はない
- loot_table: 1.13.1のloot table schemaを継承し、この版固有の追加・変更・削除はない
- recipe: 1.13.1のrecipe schemaを継承し、この版固有の追加・変更・削除はない
- item_modifier: 1.13.1を継承し、独立resourceは未対応。この版固有の追加・変更・削除はない

## AI 生成規則

1.13.1用として有効な構文だけを使い、1.13.2固有機能を捏造しません。
