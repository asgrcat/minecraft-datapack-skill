# Java Edition 1.19.2

1.19.1 のデータパック/command/JSON 仕様を継承する hotfix です。

## JSONパラメータ差分

- **item**: 1.19.1 の item JSON／NBT を継承する hotfix で、このバージョン固有の追加・変更・削除はない。
- **dimension/worldgen**: 1.19.1 の定義を継承する hotfix で、このバージョン固有の差分はない。
- **enchantment**: 固定レジストリのまま 1.19.1 を継承し、このバージョン固有の差分はない。
- **variant**: 1.19.1 の entity predicate を継承し、このバージョン固有の差分はない。
- **predicate**: 1.19.1 のpredicate形式を直接継承するhotfixで、このカテゴリ固有の追加・変更・削除はない。
- **advancement**: 1.19.1 のadvancement triggerとconditionを直接継承するhotfixで、このカテゴリ固有の追加・変更・削除はない。
- **loot_table**: 1.19.1 のloot tableとloot functionを直接継承するhotfixで、このカテゴリ固有の追加・変更・削除はない。
- **recipe**: 1.19.1 のrecipe形式を直接継承するhotfixで、このカテゴリ固有の追加・変更・削除はない。
- **item_modifier**: 1.19.1 のitem modifierを直接継承するhotfixで、このカテゴリ固有の追加・変更・削除はない。

## AI 生成規則

chat_type は1.19.1以降の形を使います。1.19.3の feature flag、recipe category、`/fillbiome` は使いません。
