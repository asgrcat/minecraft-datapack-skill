# Java Edition 1.18.2

data pack format 9。configured structure、registry tag、noise router が重要です。

## コマンド

- `/placefeature <feature> [pos]`
- `/locate` は configured structure ID または tag を参照。`/locate village` は `/locate #village`、個別なら `/locate village_desert` 等
- `/locatebiome` も biome tag を受付

## JSON

- universal registry tag: `data/<namespace>/tags/<registry-name>/...`
- experimental custom structure/structure set
- `worldgen/density_function`、`noise_settings.noise_router`
- location predicate の `feature` は configured feature reference
- exploration map destination は configured feature tag
- dimension type `infiniburn` 等、tag-only field は `#` を明示

## 互換性

1.18.1の locate command、noise settings、custom structure をそのまま使いません。custom structure はこのバージョンでは experimental です。

## JSONパラメータ差分

- item: 1.18.1の旧`tag` NBT、recipe、loot、predicate、item modifier形式を継承し、この版固有のitem stack parameter変更はない
- dimension/worldgen: `worldgen/density_function`と`noise_settings.noise_router`、experimentalな`configured_structure_feature`/`structure_set`、universal registry tagを追加。1.19以降の`structure` rootとは非互換で、`infiniburn`等のtag-only fieldは`#`を明示する
- enchantment: 固定registryを継承し、新しいenchantment definitionはJSONで追加できない
- variant: data-driven variant registryは未対応
- predicate: location predicateの`feature`をconfigured feature参照へ変更。1.19以降の`structure` fieldとは非互換
- advancement: 1.18.1のadvancement schemaを継承し、location predicateを使う条件は1.18.2のconfigured feature参照へ変更
- loot_table: `exploration_map.destination`をconfigured feature tag参照へ変更し、map表示名の自動設定を廃止。その他は1.18.1を継承
- recipe: 1.18.1のrecipe schemaを継承し、この版固有の追加・変更・削除はない
- item_modifier: 1.18.1のitem modifier schemaを継承し、この版固有の追加・変更・削除はない

## AI 生成規則

- tagを許す引数と単一ID引数を command reportで区別する
- `#` の省略をIDの自動tag解決と誤解しない
- worldgenは1.18.2生成物を正本とする
