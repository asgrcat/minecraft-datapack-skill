# Java Edition 1.18.2

data pack format 9。configured structure、registry tag、noise router が重要です。

## コマンド

- `/placefeature <feature> [pos]`
- `/locate` は configured structure ID または tag を参照。`/locate village` は `/locate #village`、個別なら `/locate village_desert` 等
- `/locatebiome` も biome tag を受付

## JSON

- universal registry tag: `data/<namespace>/tags/<registry-name>/...`
- experimental custom structure/structure set
- `worldgen/density_function`、`noise_settings.noise_router`
- location predicate の `feature` は configured feature reference
- exploration map destination は configured feature tag
- dimension type `infiniburn` 等、tag-only field は `#` を明示

## 互換性

1.18.1の locate command、noise settings、custom structure をそのまま使いません。custom structure はこのバージョンでは experimental です。

## AI 生成規則

- tagを許す引数と単一ID引数を command reportで区別する
- `#` の省略をIDの自動tag解決と誤解しない
- worldgenは1.18.2生成物を正本とする
