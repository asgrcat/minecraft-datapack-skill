# Java Edition 1.20.2

data pack format 18。function macro、行継続、overlayを正式導入します。

## function/command

- 行末の `\` で次行を連結
- `$` macro line と `$(variable)`
- `function <id> <compound>` / `function <id> with <data source> [path]`
- `/random value|roll <range> [sequence]` と sequence reset
- **正式版では** `execute if|unless function` と `return run` は削除された状態。1.20.3で再導入

## `pack.mcmeta`

- `supported_formats`。`pack_format` は引き続き必須で範囲内
- `overlays.entries[]` の `formats` と `directory`

## NBT/JSON

- mob effect NBTを snake_case + namespaced string IDへ
- `CustomPotionEffects→custom_potion_effects`, `ActiveEffects→active_effects` 等
- loot function `sequence`、predicate `all_of` のinline配列
- block/fluid state property matcherの値は数値/booleanでもJSON string必須
- scoreboard slot `belowName→below_name`

## AI 生成規則

- 開発snapshotの `return run` 例を正式1.20.2へ出力しない
- macro変数を型安全と見なさず、外部文字列をcommand位置へ挿入しない
- overlayはresource削除機能ではなくadd/replaceとして設計する
