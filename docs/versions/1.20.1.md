# Java Edition 1.20.1

1.20 のデータパック/command/JSON 仕様を変更しない hotfix です。

## JSONパラメータ差分

- **item**: 1.20 の item JSON／NBT と predicate を継承する hotfix で、このバージョン固有の追加・変更・削除はない。
- **dimension/worldgen**: 1.20 の定義を継承する hotfix で、このバージョン固有の差分はない。
- **enchantment**: 固定レジストリのまま 1.20 を継承し、このバージョン固有の差分はない。
- **variant**: 1.20 の entity predicate を継承し、このバージョン固有の差分はない。
- **predicate**: 1.20 のpredicateとloot condition形式を直接継承するhotfixで、このカテゴリ固有の追加・変更・削除はない。
- **advancement**: 1.20 のadvancement root、trigger、conditionを直接継承するhotfixで、このカテゴリ固有の追加・変更・削除はない。
- **loot_table**: 1.20 の `random_sequence`、condition、functionを直接継承するhotfixで、このカテゴリ固有の追加・変更・削除はない。
- **recipe**: 1.20 のrecipe形式を直接継承するhotfixで、このカテゴリ固有の追加・変更・削除はない。
- **item_modifier**: 1.20 のitem modifierと `reference` functionを直接継承するhotfixで、このカテゴリ固有の追加・変更・削除はない。

## AI 生成規則

format 15の1.20仕様を使います。macro、overlay、`/random` は1.20.2まで使いません。
