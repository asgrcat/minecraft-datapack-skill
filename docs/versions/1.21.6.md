# Java Edition 1.21.6

data pack format 80。全JSONをstrict modeでparseし、dialog/waypointを追加します。

## コマンド

- `/version`
- `/datapack create <id> <name>`
- `/waypoint list|modify ...`
- `/dialog`
- `playsound` に `ui` source

## JSON/NBT

- JSONのcomment、trailing comma等の非標準構文を拒否。command SNBTの許容拡張とは別
- `dialog` registry、inline dialog、`show_dialog`/custom click event
- dimension type `cloud_height`
- `painting/variant` item componentのinline variantを禁止
- area effect cloud `Particle→custom_particle`
- TNT/Vexに `owner`

## AI 生成規則

- 全 `.json` と `pack.mcmeta` をstrict JSONとして出力する
- SNBTで許されるtrailing commaをJSONへ持ち込まない
- dialog/waypointの最小版を1.21.6とする
