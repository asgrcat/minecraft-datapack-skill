# Java Edition 1.21.6

data pack format 80。全JSONをstrict modeでparseし、dialog/waypointを追加します。

## コマンド

- `/version`
- `/datapack create <id> <name>`
- `/waypoint list|modify ...`
- `/dialog`
- `playsound` に `ui` source

## JSON/NBT

- JSONのcomment、trailing comma等の非標準構文を拒否。command SNBTの許容拡張とは別
- `dialog` registry、inline dialog、`show_dialog`/custom click event
- dimension type `cloud_height`
- `painting/variant` item componentのinline variantを禁止
- area effect cloud `Particle→custom_particle`
- TNT/Vexに `owner`

## JSONパラメータ差分

- **item**: 全JSONをstrict parse。`minecraft:painting/variant` item componentはinline painting definitionを受け付けず、painting variant ID参照のみ
- **dimension/worldgen**: dimension typeへ`cloud_height`を追加。その他のdimension/worldgen codecは1.21.5を継承するが、全fileでcommentとtrailing commaを拒否
- **enchantment**: definition/effect/providerのfield集合は1.21.5を継承。enchantment JSONとinline `requirements`もstrict JSONが必須
- **variant**: visual/sound variant registryのschemaは1.21.5を継承。painting itemからのinline variantだけを削除
- **predicate**: condition/entity/item/block predicateのfield集合は1.21.5を継承するが、predicate resourceと全埋め込みpredicateをstrict JSONで記述
- **advancement**: `minecraft:player_sheared_equipment` triggerを追加。advancement root、criteria、predicate、rewardをstrict JSONで記述
- **loot_table**: root/pool/entry/condition/functionのfield集合は1.21.5を継承するが、loot table全体とinline predicateをstrict JSONで記述
- **recipe**: ingredient/result/serializer集合は1.21.5を継承するが、全recipeをstrict JSONで記述しcomment・trailing commaを削除
- **item_modifier**: function集合は1.21.5を継承するが、単一object/配列と内部condition/valueをstrict JSONで記述
- **互換性**: lenient JSONへ依存する全data fileとinline painting componentは書き換えが必要

## AI 生成規則

- 全 `.json` と `pack.mcmeta` をstrict JSONとして出力する
- SNBTで許されるtrailing commaをJSONへ持ち込まない
- dialog/waypointの最小バージョンを1.21.6とする
