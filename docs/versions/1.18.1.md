# Java Edition 1.18.1

1.18 のデータパック/command/JSON 仕様を継承します。server protocol の1.18互換は pack schemaとは別の性質です。

## JSONパラメータ差分

- item: `inherits: 1.18`。item、recipe、loot、predicate、item modifier parameterにこのバージョン固有の変更はない
- dimension/worldgen: 1.18の高さ・noise・terrain schemaを継承し、このバージョン固有の変更はない
- enchantment: 1.18の固定registryとitem NBT形式を継承
- variant: 1.18を継承し、data-driven variant registryはない
- predicate: 1.18のpredicate schemaを継承し、このバージョン固有の追加・変更・削除はない
- advancement: 1.18のadvancement schemaを継承し、このバージョン固有の追加・変更・削除はない
- loot_table: 1.18のloot table schemaを継承し、このバージョン固有の追加・変更・削除はない
- recipe: 1.18のrecipe schemaを継承し、このバージョン固有の追加・変更・削除はない
- item_modifier: 1.18のitem modifier schemaを継承し、このバージョン固有の追加・変更・削除はない

## AI 生成規則

1.18の worldgen/loot schemaを使用し、1.18.2の `/locate` 変更を使いません。
