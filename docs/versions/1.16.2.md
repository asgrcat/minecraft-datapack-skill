# Java Edition 1.16.2

data pack format 6。custom world generation の実験的データ駆動化を拡大します。

## JSON

`data/<namespace>/worldgen/` に次を追加:

```text
biome
configured_carver
configured_feature
configured_structure_feature
configured_surface_builder
noise_settings
processor_list
template_pool
```

custom biome を custom dimension と single-biome/caves/floating-islands で利用できます。pack root の `pack.png` にも対応します。

## コマンドと意味変更

- `spawnpoint`, `setworldspawn` の末尾に `[angle]`
- `execute in` の relative X/Z は Overworld↔Nether で1:8 scaling。旧挙動が必要なら `execute in <dimension> positioned as @s ...` のように位置を再指定

## tag

`mushroom_grow_block`, `base_stone_nether`, `base_stone_overworld`, `stone_crafting_materials` 等を追加し、`furnace_materials` item tag を削除。

## 互換性

1.16/1.16.1の experimental dimension/worldgen は schema 変動が大きいため作り直して検証します。custom worldgen は引き続き experimental です。

## AI 生成規則

- worldgen は1.16.2 server JARの vanilla/generated dataを基底にする
- 1.17+の worldgen JSONを流用しない
- `execute in` の scalingを座標計算に二重適用しない
