# Java Edition 1.16.2

data pack format 6。custom world generation の実験的データ駆動化を拡大します。

## JSON

`data/<namespace>/worldgen/` に次を追加:

```text
biome
configured_carver
configured_feature
configured_structure_feature
configured_surface_builder
noise_settings
processor_list
template_pool
```

custom biome を custom dimension と single-biome/caves/floating-islands で利用できます。pack root の `pack.png` にも対応します。

## コマンドと意味変更

- `spawnpoint`, `setworldspawn` の末尾に `[angle]`
- `execute in` の relative X/Z は Overworld↔Nether で1:8 scaling。旧挙動が必要なら `execute in <dimension> positioned as @s ...` のように位置を再指定

## tag

`mushroom_grow_block`, `base_stone_nether`, `base_stone_overworld`, `stone_crafting_materials` 等を追加し、`furnace_materials` item tag を削除。

## 互換性

1.16/1.16.1の experimental dimension/worldgen は schema 変動が大きいため作り直して検証します。custom worldgen は引き続き experimental です。

## JSONパラメータ差分

- item: 旧`tag` NBTと1.16のrecipe/loot形式を継承。item tagを追加し、`furnace_materials`を削除したためtag参照は1.16.2生成物へ合わせる
- dimension/worldgen: format 6へ移行し、`worldgen/biome`、configured carver/feature/structure feature/surface builder、noise settings、processor list、template poolを追加。custom biomeをdimension generatorから参照できる
- enchantment: 固定registryを継承し、新しいenchantment definitionはJSONで追加できない
- variant: data-driven variant registryは未対応。biome追加はentity variant定義とは別
- predicate: 1.16.1のpredicate schemaを継承し、このバージョン固有の追加・変更・削除はない
- advancement: 1.16.1のadvancement schemaを継承し、このバージョン固有の追加・変更・削除はない
- loot_table: 1.16.1のloot table schemaを継承し、このバージョン固有の追加・変更・削除はない
- recipe: 1.16.1のrecipe schemaを継承し、このバージョン固有の追加・変更・削除はない
- item_modifier: 1.16.1を継承し、独立resourceは未対応。このバージョン固有の追加・変更・削除はない

## AI 生成規則

- worldgen は1.16.2 server JARの vanilla/generated dataを基底にする
- 1.17+の worldgen JSONを流用しない
- `execute in` の scalingを座標計算に二重適用しない
