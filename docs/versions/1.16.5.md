# Java Edition 1.16.5

server crash の hotfix です。データパック仕様は1.16.4を継承します。1.16.4 client と1.16.5 server の network 互換は、pack schema の新機能を意味しません。

## JSONパラメータ差分

- item: `inherits: 1.16.4`。item、recipe、loot、predicate parameterにこの版固有の変更はない
- dimension/worldgen: 1.16.4のformat 6とexperimental worldgen schemaを継承し、この版固有の変更はない
- enchantment: 1.16.4の固定registryとitem NBT形式を継承
- variant: 1.16.4を継承し、data-driven variant registryはない
- predicate: 1.16.4のpredicate schemaを継承し、この版固有の追加・変更・削除はない
- advancement: 1.16.4のadvancement schemaを継承し、この版固有の追加・変更・削除はない
- loot_table: 1.16.4のloot table schemaを継承し、この版固有の追加・変更・削除はない
- recipe: 1.16.4のrecipe schemaを継承し、この版固有の追加・変更・削除はない
- item_modifier: 1.16.4を継承し、独立resourceは未対応。この版固有の追加・変更・削除はない

## AI 生成規則

format 6の最終バージョンとして1.16.2の worldgen境界を保持し、1.17の `/item` を使いません。
