# Java Edition 1.19.3

形式10のまま技術変更が多い版です。`data_pack_format: 12` ではありません。

## コマンド

- `/fillbiome <from> <to> <biome> [replace <filter>]`
- `/execute if|unless biome`
- `/publish [allowCommands] [gamemode] [port]`

## JSON

- `pack.mcmeta.features.enabled[]` で experimental feature flag
- recipe の optional `category`。crafting は `building|redstone|equipment|misc`、cooking は `food|blocks|misc`
- entity predicate `type_specific` に axolotl/boat/fox/mooshroom/painting/rabbit/horse/llama/villager/parrot/tropical_fish 等
- `#minecraft:load` が `#minecraft:tick` より先に実行されるよう修正

## 互換性

同じ format 10の1.19.2へ `/fillbiome` や category 付き resourceを持ち込まない。feature flag依存 resourceは flag未有効 worldで利用できません。

## AI 生成規則

- `target_version` を必ず1.19.3まで判定してから command/resourceを選ぶ
- experimental update resourcesをstable baselineに混ぜない
