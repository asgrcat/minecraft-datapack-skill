# Java Edition 1.19.3

形式10のまま技術変更が多いバージョンです。`data_pack_format: 12` ではありません。

## コマンド

- `/fillbiome <from> <to> <biome> [replace <filter>]`
- `/execute if|unless biome`
- `/publish [allowCommands] [gamemode] [port]`

## JSON

- `pack.mcmeta.features.enabled[]` で experimental feature flag
- recipe の optional `category`。crafting は `building|redstone|equipment|misc`、cooking は `food|blocks|misc`
- entity predicate `type_specific` に axolotl/boat/fox/mooshroom/painting/rabbit/horse/llama/villager/parrot/tropical_fish 等
- `#minecraft:load` が `#minecraft:tick` より先に実行されるよう修正

## 互換性

同じ format 10の1.19.2へ `/fillbiome` や category 付き resourceを持ち込まない。feature flag依存 resourceは flag未有効 worldで利用できません。

## JSONパラメータ差分

- **item**: アイテムスタックの NBT 形式は 1.19.2 を継承する。recipe に追加された `category` はレシピブック上の分類であり、アイテムスタック形式の変更ではない。
- **dimension/worldgen**: 1.19.3 の generated data を基準に再取得する。stronghold 配置アルゴリズムの変更により同一 seed でも位置がずれる場合があり、無効な feature flag に属する block／entity は structure から読み込み・生成されないため、実験的 worldgen は対応する flag を有効にしたワールド専用となる。
- **enchantment**: 固定レジストリのまま 1.19.2 を継承し、このバージョン固有の JSON 差分はない。
- **variant**: entity predicate の `type_specific` に axolotl、boat、fox、mooshroom、painting、rabbit、horse、llama、villager、parrot、tropical fish 用 sub-predicate を追加。これらは 1.19.2 以前と互換ではない。
- **predicate**: entity predicate の `type_specific.type` にaxolotl、boat、fox、mooshroom、painting、rabbit、horse、llama、villager、parrot、tropical_fish等を追加。追加typeを含むpredicateは1.19.2以前で解釈できないため、対象バージョンを分ける。
- **advancement**: advancementのrootとtrigger集合は1.19.2を継承する。criteria内のentity predicateでは1.19.3追加の `type_specific` を利用できるが、そのconditionを含むadvancementは1.19.2以前と非互換。
- **loot_table**: loot tableのroot、entry、condition、functionは1.19.2を継承する。entity判定を含むloot conditionでは1.19.3追加の `type_specific` が使えるため、旧バージョン互換範囲を広げない。
- **recipe**: recipe book対応typeへ任意の `category` を追加。crafting系は `building|redstone|equipment|misc`、cooking系は `food|blocks|misc` を使い、未指定時は `misc`。このfieldは1.19.2以前へ持ち込まない。
- **item_modifier**: item modifierのfunction形式は1.19.2を継承し、このカテゴリ固有の追加・変更・削除はない。condition内で新しいentity `type_specific` を使う場合のみ1.19.3以降が必要。

## AI 生成規則

- `target_version` を必ず1.19.3まで判定してから command/resourceを選ぶ
- experimental update resourcesをstable baselineに混ぜない
