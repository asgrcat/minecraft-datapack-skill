# Java Edition 1.17

data pack format 7。item 操作と loot/predicate の型が変わります。

## コマンド

- `/item replace <target> with <stack> [count]`
- `/item replace <target> from <source> [modifier]`
- `/item modify <target> <modifier>`
- target/source は `entity <selector> <slot>` または `block <pos> <slot>`
- `/replaceitem` を削除
- `/debug function <function>`、`/perf`

## JSON

- `data/<namespace>/item_modifiers/<id>.json`。loot function object または配列
- loot condition `value_check`、number provider `score`
- score condition の `entity` → `target`
- item predicate `item` → `items` 配列
- `set_damage`, `set_count` に `add`。`copy_nbt.source` に storage
- advancement trigger `started_riding`, `lightning_strike`, `using_item`

## 互換性

1.16.5の `/replaceitem` は load error になるため全置換します。loot table の `set_damage` 等は型検査をやり直します。

## AI 生成規則

- item modifier の最小バージョンは1.17
- component patch 構文は1.20.5まで使わない
- Java 16 runtime を必要とする点は server 検証時に考慮する
